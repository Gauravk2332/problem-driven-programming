02 / How a lecture works

One problem, six steps

Every published lecture follows a problem-first learning path. Module 01 covers algorithm fundamentals, complexity, asymptotic notation, recurrences and design strategies. Module 02 covers primes, sieve, Euclid, modular arithmetic, Catalan numbers and pigeonhole principle. Module 03 covers hashing and collisions. Module 04 covers greedy strategy, fractional knapsack, intervals, jobs, heaps, scheduling and correctness. Lecture 19 builds DP intuition; Lecture 20 derives a minimum-energy jump recurrence, then compares memoization, tabulation and rolling storage. Lecture 21 develops two-dimensional 0/1 Knapsack, including item reconstruction and memory optimization. Lecture 22 allows repeated selection and distinguishes minimum coins, unordered combinations and ordered sequences. Lecture 23 introduces Boolean feasibility, subset reconstruction and equal partition. Lecture 24 introduces sequence DP and binary-search optimization. Lecture 25 develops two-prefix string DP, edit-script reconstruction and rolling rows. Lecture 26 introduces interval, bitmask and digit DP. Lecture 27 integrates algorithm selection, weighted scheduling, fast I/O and systematic testing.

03 / Try it

Build Fibonacci from stored answers

A small sample of the labs inside each lecture. Press Next and predict each value before it appears.

From Lecture 19

Reuse the last two answers

Start from the base cases F(0) and F(1). Each new value needs only the two values already in the table, so nothing is computed twice. Lecture 20 turns this idea into a complete design process.

Enable JavaScript to step through the table.

Lecture 19 has four full labs: a recursion tree, a bottom-up table, a work-count comparison and a greedy-versus-DP coin table. Open the recursion tree lab. Lecture 20 has three linked labs: memoization, tabulation and rolling state. Lecture 21 builds a 2D knapsack table and explores capacity loop direction. Lecture 22 compares unbounded knapsack and coin-counting loops. Lecture 23 builds a Boolean DP table and tests equal partitions. Lecture 24 traces endpoint DP and minimum tails. Lecture 25 builds an edit-distance matrix and executes an optimal edit script. Lecture 26 explores matrix-chain splits, assignment masks and bounded digits. Lecture 27 connects weighted scheduling with differential testing. All nine lectures of the DP learning path are now published.
