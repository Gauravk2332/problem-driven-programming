Algorithm

A finite sequence of well-defined, effective steps mapping valid inputs to the required output, terminating for every valid input. A program implements an algorithm.

Five characteristics

Meaning
Inputzero or more
Outputat least one
Definitenesseach step unambiguous
Finitenessstops for every valid input
Effectivenesseach step basic and exact

Specification

Pre: guaranteed about the input. Post: required of the output. Correct = terminates and meets post for every input meeting pre.

Max algorithm

best ← A[0]
for i ← 1..n−1: if A[i] > best: best ← A[i]
return best

n − 1 comparisons, Θ(n) time, O(1) space. [12,7,19,4,19,8] → 19.

Loop invariant proof

Invariant
best = max(A[0..i−1])
Initialisation
i = 1: best = A[0]
Maintenance
both branches give max(A[0..i])
Termination
i = n ⇒ best = max(A)

Common mistakes · full marks

  • Passing tests ≠ proof.
  • best = 0 fails on all-negative input.
  • Finiteness ≠ efficiency.

Full marks: define, list all five characteristics with examples, specify, prove with an invariant, give complexity.

Two-mark self-test

  1. Define an algorithm.
    A finite sequence of well-defined, effective steps that takes zero or more inputs and produces at least one output, terminating for every valid input.
  2. Distinguish an algorithm from a program.
    An algorithm is a language-independent method; a program is its implementation in a specific language for a machine. One algorithm can have many programs.
  3. What is definiteness? Give a step that violates it.
    Each step has exactly one precise meaning. “Add a little salt” or “repeat until done” without a test violates it.
  4. State the five characteristics of an algorithm.
    Input, output, definiteness, finiteness, effectiveness.
  5. What are a precondition and a postcondition?
    Precondition: what holds for the input before execution. Postcondition: what must hold for the output after execution, given the precondition.
