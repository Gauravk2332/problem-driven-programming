Start with a problem

Imagine preparing tea: choose ingredients, heat water, add tea, simmer, strain and serve. A recipe is a procedure, but “heat until ready” is ambiguous unless we specify an observable stopping condition. An algorithm needs precise steps and must terminate for its intended inputs.

Now consider a computer problem: find the largest among the marks [12,7,19,4,19,8]. You may inspect them one at a time. How much information must you remember?

Chapter 02 / 07

Understand the concept

An algorithm is a finite, well-defined sequence of effective steps that maps valid inputs to the specified output. A program is an implementation of an algorithm in a programming language; the same algorithm can have several implementations.

CharacteristicMeaning
InputZero or more specified inputs
OutputAt least one specified result
DefinitenessEach step is unambiguous
FinitenessTerminates for every valid input
EffectivenessEach step is mechanically executable
CorrectnessMeets the specification on valid inputs

Describe a solution using natural language, pseudocode, flowchart or executable code. Specify preconditions and postconditions. Example: nonempty array of comparable integers → return a value present in it that is at least every other value. Do not initialize maximum to zero: all-negative arrays expose that bug.

best = A[0]
for i = 1..n−1:
  if A[i] > best: best = A[i]
return best

Loop invariant: after reading the first i≥1 elements, best equals their maximum. Initialization: the first element establishes it. Maintenance: comparing the next value preserves it. Termination: the last iteration has examined the whole array. The loop uses n−1 comparisons and O(1) auxiliary space. Empty arrays require a separate contract or error.

ParadigmIdeaExample
Brute forceTry candidate solutionsExhaustive subset search

GreedyCommit to a proven safe local choiceActivity selection

BacktrackingExplore choices, abandon invalid partial solutionsN-queens

These are design approaches, not mutually exclusive categories. Choose according to structure and constraints, not a keyword.

Implement and analyse

def maximum(a):
    if not a: raise ValueError("nonempty array required")
    best=a[0]
    for i in range(1,len(a)):
        if a[i]>best: best=a[i]
    return best
print(maximum([12,7,19,4,19,8]))
#include <iostream>
#include <vector>
#include <stdexcept>
using namespace std;
int maximum(const vector<int>& a){
 if(a.empty())throw invalid_argument("nonempty required");
 int best=a[0];
 for(size_t i=1;i<a.size();i++)
  if(a[i]>best)best=a[i];
 return best;
}
int main(){cout<<maximum({12,7,19,4,19,8})<<"\n";}
class Main{
 static int maximum(int[] a){
  if(a.length==0)throw new IllegalArgumentException("nonempty required");
  int best=a[0];
  for(int i=1;i<a.length;i++)if(a[i]>best)best=a[i];
  return best;
 }
 public static void main(String[] args){
  System.out.println(maximum(new int[]{12,7,19,4,19,8}));
 }
}

Exam revision

Algorithm: precise, finite, effective steps and specified result. State valid inputs and outputs. Correctness needs argument, not just successful examples. Invariant proves a loop by initialization, maintenance and termination. Maximum scan uses n−1 comparisons, Θ(n) time, Θ(1) auxiliary space.
