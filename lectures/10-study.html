Start with a problem

A university has 10,000 students with roll numbers up to 10⁹. The library gate must check, thousands of times a day, whether a scanned roll number is registered.

Hash tableexpected O(1)collisions must be handled
Think first

Direct addressing is fast but wastes memory. How could you get its speed with a table of only, say, 20,000 slots?

Compress the key
Compute a slot from the key, for example roll mod 20,011, and store the roll number there. Different keys may land in the same slot (a collision), so the slot must be able to hold more than one key and we must compare the actual keys.

Chapter 02 / 13

Keys, hash functions and buckets

  • Key: what we look up (roll number, word). A map stores key → value pairs; a set stores keys only.
  • Hash function h: maps a key to an index 0 … m − 1, called its bucket or slot.
  • Hash table: an array of m buckets plus a rule for collisions.
  • Collision: two different keys with the same hash value. With more possible keys than slots, collisions are unavoidable (pigeonhole, Lecture 9).

A good hash function is deterministic (the same key always gives the same index), fast, and spreads typical keys uniformly over the buckets. Equal keys must hash equally; equal hashes do not imply equal keys, so a table always compares keys after hashing.

Two keys have the same hash value. What can you conclude?

Chapter 03 / 13

Common hash functions

MethodFormulaNotes
Divisionh(k) = k mod mchoose m prime and not close to a power of 2
Multiplicationh(k) = ⌊m · frac(k·A)⌋, 0 < A < 1m can be a power of 2; Knuth suggests A ≈ 0.618
Foldingsplit the key into parts and add themfor long numeric keys such as phone numbers
Mid-squaresquare k and take middle digitsclassic textbook method
Polynomial (strings)h(s) = Σ (s[i] − 'a' + 1)·pⁱ mod Morder matters: “abc” ≠ “cab”

Why a prime m for division hashing: if m = 10, h depends only on the last digit, and keys ending in 0 all collide; if all keys are multiples of some d sharing a factor with m, only m/gcd(d, m) buckets are ever used. A prime m uses every bucket for any key pattern except multiples of m itself.

For negative keys in C++ or Java, k % m can be negative: use ((k % m) + m) % m (Lecture 8).

Chapter 06 / 13

Load factor and cost

The load factor is α = n/m, the average number of keys per bucket. In the example α = 6/7 ≈ 0.86.

Operation (chaining)Expected timeWorst case
Insert (no duplicate check)O(1)O(1)
Search / insert with checkO(1 + α)O(n): every key in one bucket
DeleteO(1 + α)O(n)

The expected bounds assume simple uniform hashing: each key is equally likely to go to any bucket, independently. Keeping α bounded (by growing the table, Lecture 11) makes the operations expected O(1). The worst case happens with a bad hash function or adversarial keys, as in the multiples-of-7 experiment.

Unlike a sorted structure, a hash table does not keep keys in order: finding the minimum or listing keys in order costs O(n) or a sort.

Two-sum by checking all pairs is Θ(n²). With a map, scan once: for each x, check whether target − x was seen, then record x. Θ(n) expected time, Θ(n) space: a classic time–memory trade.

Chapter 08 / 13

Hashing strings

Treat a string as a number in base p: h(s) = Σ (s[i] − 'a' + 1) · pⁱ mod M, with p = 31 and M = 10⁹ + 9.

StringComputationHash
abc1 + 2·31 + 3·9612946
cab3 + 1·31 + 2·9611956
  • Position matters, so anagrams get different hashes (unlike simply adding letter codes).
  • Letters map to 1 … 26, not 0 … 25, so “a” and “aa” differ.
  • Distinct strings can still collide (there are far more strings than values below M): compare the strings when hashes match, or use two moduli.
  • Rolling hash: the hash of a sliding window can be updated in O(1), which gives the Rabin–Karp substring search.

Chapter 09 / 13

Hashing in code

The program implements a small chained hash set, then uses each language’s built-in map and set for word frequencies, two-sum and counting distinct values, and computes polynomial string hashes.

Python · hashing.py

"""Lecture 10: hash functions, a chained hash set, maps and sets in practice."""


class ChainedHashSet:
    def __init__(self, m):
        self.buckets = [[] for _ in range(m)]

    def index(self, key):
        return key % len(self.buckets)      # Python % is never negative

    def add(self, key):
        b = self.buckets[self.index(key)]
        if key not in b:
            b.append(key)

    def contains(self, key):
        return key in self.buckets[self.index(key)]


def poly_hash(s, base=31, mod=1_000_000_009):
    h, power = 0, 1
    for ch in s:
        h = (h + (ord(ch) - ord('a') + 1) * power) % mod
        power = power * base % mod
    return h


def two_sum(nums, target):
    where = {}
    for i, x in enumerate(nums):
        if target - x in where:
            return where[target - x], i
        where[x] = i
    return None


t = ChainedHashSet(7)
for k in [15, 11, 27, 8, 12, 20]:
    t.add(k)
for i, b in enumerate(t.buckets):
    print(f"bucket {i}: {b}")
print("contains 8:", t.contains(8), "| contains 22:", t.contains(22))
freq = {}
for w in "the cat and the hat and the bat".split():
    freq[w] = freq.get(w, 0) + 1
print("frequencies:", ", ".join(f"{w}={freq[w]}" for w in sorted(freq)))
print("two_sum([2, 7, 11, 15], 9) ->", two_sum([2, 7, 11, 15], 9))
print("distinct in [3, 1, 3, 2, 1]:", len(set([3, 1, 3, 2, 1])))
print("poly_hash('abc') =", poly_hash("abc"), "| poly_hash('cab') =", poly_hash("cab"))

C++ · hashing.cpp

// Lecture 10: hash functions, a chained hash set, maps and sets in practice.
#include <cstdio>
#include <map>
#include <sstream>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

struct ChainedHashSet {
    vector<vector<int>> buckets;
    explicit ChainedHashSet(int m) : buckets(m) {}
    int index(int key) const { int m = buckets.size(); return ((key % m) + m) % m; }   // C++ % can be negative
    void add(int key) {
        auto& b = buckets[index(key)];
        for (int x : b) if (x == key) return;
        b.push_back(key);
    }
    bool contains(int key) const {
        for (int x : buckets[index(key)]) if (x == key) return true;
        return false;
    }
};

long long polyHash(const string& s, long long base = 31, long long mod = 1000000009LL) {
    long long h = 0, power = 1;
    for (char ch : s) {
        h = (h + (ch - 'a' + 1) * power) % mod;
        power = power * base % mod;
    }
    return h;
}

bool twoSum(const vector<int>& nums, int target, int& i1, int& i2) {
    unordered_map<int, int> where;
    for (int i = 0; i < (int)nums.size(); i++) {
        auto it = where.find(target - nums[i]);
        if (it != where.end()) { i1 = it->second; i2 = i; return true; }
        where[nums[i]] = i;
    }
    return false;
}

int main() {
    ChainedHashSet t(7);
    for (int k : {15, 11, 27, 8, 12, 20}) t.add(k);
    for (size_t i = 0; i < t.buckets.size(); i++) {
        printf("bucket %zu: [", i);
        for (size_t j = 0; j < t.buckets[i].size(); j++) printf("%s%d", j ? ", " : "", t.buckets[i][j]);
        printf("]\n");
    }
    printf("contains 8: %s | contains 22: %s\n", t.contains(8) ? "True" : "False", t.contains(22) ? "True" : "False");
    map<string, int> freq;                       // ordered map: keys print sorted
    istringstream in("the cat and the hat and the bat");
    for (string w; in >> w;) freq[w]++;
    printf("frequencies: ");
    bool first = true;
    for (auto& [w, c] : freq) { printf("%s%s=%d", first ? "" : ", ", w.c_str(), c); first = false; }
    printf("\n");
    int a, b;
    twoSum({2, 7, 11, 15}, 9, a, b);
    printf("two_sum([2, 7, 11, 15], 9) -> (%d, %d)\n", a, b);
    unordered_set<int> distinct = {3, 1, 3, 2, 1};
    printf("distinct in [3, 1, 3, 2, 1]: %zu\n", distinct.size());
    printf("poly_hash('abc') = %lld | poly_hash('cab') = %lld\n", polyHash("abc"), polyHash("cab"));
}

Java · Hashing.java

// Lecture 10: hash functions, a chained hash set, maps and sets in practice.
import java.util.*;

public class Hashing {
    static class ChainedHashSet {
        final List<List<Integer>> buckets = new ArrayList<>();
        ChainedHashSet(int m) { for (int i = 0; i < m; i++) buckets.add(new ArrayList<>()); }
        int index(int key) { return Math.floorMod(key, buckets.size()); }   // Java % can be negative
        void add(int key) {
            List<Integer> b = buckets.get(index(key));
            if (!b.contains(key)) b.add(key);
        }
        boolean contains(int key) { return buckets.get(index(key)).contains(key); }
    }

    static long polyHash(String s) {
        long base = 31, mod = 1_000_000_009L, h = 0, power = 1;
        for (char ch : s.toCharArray()) {
            h = (h + (ch - 'a' + 1) * power) % mod;
            power = power * base % mod;
        }
        return h;
    }

    static int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> where = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            Integer j = where.get(target - nums[i]);
            if (j != null) return new int[]{j, i};
            where.put(nums[i], i);
        }
        return null;
    }

    public static void main(String[] args) {
        ChainedHashSet t = new ChainedHashSet(7);
        for (int k : new int[]{15, 11, 27, 8, 12, 20}) t.add(k);
        for (int i = 0; i < t.buckets.size(); i++) System.out.println("bucket " + i + ": " + t.buckets.get(i));
        System.out.println("contains 8: " + (t.contains(8) ? "True" : "False") + " | contains 22: " + (t.contains(22) ? "True" : "False"));
        Map<String, Integer> freq = new TreeMap<>();   // TreeMap: keys print sorted
        for (String w : "the cat and the hat and the bat".split(" ")) freq.merge(w, 1, Integer::sum);
        StringJoiner sj = new StringJoiner(", ");
        freq.forEach((w, c) -> sj.add(w + "=" + c));
        System.out.println("frequencies: " + sj);
        int[] r = twoSum(new int[]{2, 7, 11, 15}, 9);
        System.out.println("two_sum([2, 7, 11, 15], 9) -> (" + r[0] + ", " + r[1] + ")");
        Set<Integer> distinct = new HashSet<>();
        for (int x : new int[]{3, 1, 3, 2, 1}) distinct.add(x);
        System.out.println("distinct in [3, 1, 3, 2, 1]: " + distinct.size());
        System.out.println("poly_hash('abc') = " + polyHash("abc") + " | poly_hash('cab') = " + polyHash("cab"));
    }
}

Chapter 10 / 13

Common confusions

ConfusionCorrection
“Hash tables are always O(1).”Expected O(1) with a good hash and bounded α; worst case O(n).
“Equal hashes mean equal keys.”Collisions exist; compare keys.
“Hashing is encryption.”Table hashing is for speed; cryptographic hashes are a different tool with security goals.
“unordered_map and map are the same.”map is a balanced tree: ordered, O(log n).
“Any m works for k mod m.”Patterned keys collide when m shares factors with the pattern; prefer a prime m.
