Open addressing

All keys in the array; probe h(k, 0), h(k, 1), … Insert at first EMPTY/DELETED; search until key or EMPTY. α = n/m ≤ 1.

Probe functions

Methodh(k, i)Clustering
Linear(h + i) mod mprimary
Quadratic(h + i²) mod msecondary
Double(h₁ + i·h₂) mod m≈ none

Quadratic: prime m, α ≤ ½. Double: h₂ ≠ 0, coprime with m.

Example: 89, 18, 49, 58, 69, m = 10

Deletion

Tombstone X: search continues past it; insert may reuse it. Delete 49 → search 58 still found at 1; insert 79 reuses slot 0.

Load factor & rehashing

Linear: successful ≈ ½(1 + 1/(1−α)), unsuccessful ≈ ½(1 + 1/(1−α)²): α = 0.5 → 1.5 / 2.5; 0.9 → 5.5 / 50.5. Rehash at α ≈ 0.5–0.75 to ≈ 2m (prime); amortised O(1).

Common mistakes · full marks

  • Never empty a slot on delete.
  • Re-hash every key when resizing.
  • Open hashing = chaining.

Full marks: probe function, table after each insert with probes, clustering, tombstones, α and rehashing.

Two-mark self-test

  1. What is open addressing?
    A collision-resolution method that stores all keys in the table array and, on collision, probes a sequence of other slots.
  2. Write the probe functions of linear and quadratic probing.
    Linear (h(k) + i) mod m; quadratic (h(k) + i²) mod m.
  3. What is primary clustering?
    Long runs of occupied consecutive slots formed by linear probing; keys hashing into a run extend it.
  4. Why are tombstones needed?
    Emptying a slot would stop later searches early; a tombstone lets searches continue and insertions reuse the slot.
  5. What is rehashing?
    Creating a larger table and re-inserting every key with the new hash function when the load factor passes a threshold.
