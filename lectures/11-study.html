Chapter 01 / 14

Start with a problem

Insert the keys 89, 18, 49, 58, 69 into a table of 10 slots with h(k) = k mod 10, storing one key per slot and no linked lists.

Think first

89 goes to slot 9 and 18 to slot 8. Where should 49 go? Then 58 and 69?

Probe for the next free slot
49 wants slot 9 (taken), so try 0: free. 58 wants 8, then 9, 0, finally 1. 69 wants 9, then 0, 1, finally 2. Every key fits, but later keys need longer and longer searches.

This is open addressing: all keys live in the array, and a collision is resolved by trying a sequence of other slots, the probe sequence. It saves the pointers and memory allocation of chaining (Lecture 10), at the cost of more care with load and deletion.

Open addressing defines a probe sequence h(k, 0), h(k, 1), …, h(k, m − 1). Insert takes the first empty slot; search follows the same sequence until it finds the key or an empty slot, which proves the key is absent.

Primary clustering: occupied slots form long runs, and any key hashing into a run must walk to its end, making the run longer still. A run of length L is hit with probability about (L + 1)/m, so big clusters grow fastest.

Chapter 04 / 14

Explore: three probing strategies

Insert the same keys with each method and compare total probes. The double-hashing step is h₂(k) = 7 − (k mod 7).

Think first

With quadratic probing, try keys 1 2 3 4 5 and m = 4. Can every key be placed?

Quadratic probing can miss free slots
Offsets i² mod 4 are only 0 and 1, so a key can never reach two of the four slots. The fifth key cannot fit anyway, but even a free slot may be unreachable. With a prime m and α ≤ ½, quadratic probing always finds a free slot.

Chapter 06 / 14

Double hashing

h(k, i) = (h₁(k) + i · h₂(k)) mod m,   here h₁(k) = k mod 10, h₂(k) = 7 − (k mod 7)
Keyh₁h₂Probe sequenceSlot
899299
188388
49979, 66
58858, 33
69919, 00

The step size depends on the key, so two keys with the same home slot usually follow different paths: no primary or secondary clustering. Total probes: 8, the fewest of the three.

  • h₂(k) must never be 0 (that is why it is 7 − (k mod 7), in 1…7).
  • h₂(k) should be coprime with m so the sequence can visit every slot; making m prime guarantees this. (Here m = 10, so a step of 5 would only visit two slots; a real table should use a prime m.)

Chapter 07 / 14

Deletion and tombstones

Suppose we simply empty 49’s slot (slot 0) after linear probing. A later search for 58 starts at 8, sees 8 and 9 full and then slot 0 empty, and wrongly reports “not present”, although 58 sits in slot 1.

The fix is a tombstone (marked X): a deleted slot that

  • does not stop a search (keep probing past it), but
  • can be reused by an insertion.

The program deletes 49, still finds 58 at slot 1, and inserts 79 into the tombstone at slot 0 after 2 probes. Tombstones accumulate and lengthen searches, so tables are periodically rebuilt (rehashed) to clear them. Chaining needs none of this.

Chapter 08 / 14

Load factor, expected probes and rehashing

For linear probing with uniform hashing (Knuth’s analysis), the expected number of probes is about

successful search ≈ ½ (1 + 1/(1 − α)),   unsuccessful/insert ≈ ½ (1 + 1/(1 − α)²)
αSuccessfulUnsuccessful
0.51.52.5
0.752.58.5
0.95.550.5

Cost explodes as α → 1, so tables rehash: when α would exceed a threshold (often 0.5–0.75), allocate a larger table (about twice the size, rounded to a prime) and re-insert every key with the new m. One rehash costs O(n), but doubling makes it rare: the cost spread over all insertions is amortised O(1).

The program starts with m = 5 and threshold 0.7: inserting the fourth key would give α = 0.8, so it rehashes into m = 11 and finishes with 5 keys at α ≈ 0.45.

Why must every key be re-inserted after resizing, rather than copied to the same index?

Python · open_addressing.py

"""Lecture 11: open addressing (linear, quadratic, double hashing), deletion, rehashing."""
EMPTY, DELETED = None, "DEL"


def probe(key, i, m, mode):
    h = key % m
    if mode == "linear":
        return (h + i) % m
    if mode == "quadratic":
        return (h + i * i) % m
    return (h + i * (7 - key % 7)) % m          # double hashing, h2(k) = 7 - (k mod 7)


def insert(table, key, mode):
    m = len(table)
    for i in range(m):
        j = probe(key, i, m, mode)
        if table[j] is EMPTY or table[j] == DELETED:
            table[j] = key
            return i + 1                          # probes used
    return -1


def search(table, key, mode):
    m = len(table)
    for i in range(m):
        j = probe(key, i, m, mode)
        if table[j] is EMPTY:
            return -1
        if table[j] == key:
            return j
    return -1


def show(table):
    return " ".join("." if x is EMPTY else ("X" if x == DELETED else str(x)) for x in table)


keys = [89, 18, 49, 58, 69]
for mode in ["linear", "quadratic", "double"]:
    t = [EMPTY] * 10
    probes = [insert(t, k, mode) for k in keys]
    print(f"{mode:9} m=10: {show(t)}   probes {probes} total {sum(probes)}")
t = [EMPTY] * 10
for k in keys:
    insert(t, k, "linear")
t[search(t, 49, "linear")] = DELETED
print("linear, after deleting 49:", show(t))
print("search 58 ->", search(t, 58, "linear"), "| search 49 ->", search(t, 49, "linear"))
print("insert 79 uses", insert(t, 79, "linear"), "probes:", show(t))
m, n, table = 5, 0, [EMPTY] * 5
for k in [12, 7, 3, 18, 25]:
    if (n + 1) / m > 0.7:
        old = [x for x in table if x is not EMPTY]
        m = 11
        table = [EMPTY] * m
        for x in old:
            insert(table, x, "linear")
        print(f"load would exceed 0.7 -> rehash to m={m}: {show(table)}")
    insert(table, k, "linear")
    n += 1
print(f"final m={m}, n={n}, load factor = {n / m:.2f}: {show(table)}")

C++ · open_addressing.cpp

// Lecture 11: open addressing (linear, quadratic, double hashing), deletion, rehashing.
#include <cstdio>
#include <string>
#include <vector>
using namespace std;
const int EMPTY = -1, DELETED = -2;        // keys are non-negative

int probe(int key, int i, int m, const string& mode) {
    int h = key % m;
    if (mode == "linear") return (h + i) % m;
    if (mode == "quadratic") return (h + i * i) % m;
    return (h + i * (7 - key % 7)) % m;    // double hashing, h2(k) = 7 - (k mod 7)
}

int insertKey(vector<int>& t, int key, const string& mode) {   // returns probes used, -1 if full
    int m = t.size();
    for (int i = 0; i < m; i++) {
        int j = probe(key, i, m, mode);
        if (t[j] == EMPTY || t[j] == DELETED) { t[j] = key; return i + 1; }
    }
    return -1;
}

int search(const vector<int>& t, int key, const string& mode) {
    int m = t.size();
    for (int i = 0; i < m; i++) {
        int j = probe(key, i, m, mode);
        if (t[j] == EMPTY) return -1;          // an empty slot ends the search
        if (t[j] == key) return j;             // a DELETED slot does not
    }
    return -1;
}

string show(const vector<int>& t) {
    string s;
    for (size_t i = 0; i < t.size(); i++) s += (i ? " " : "") + (t[i] == EMPTY ? string(".") : t[i] == DELETED ? string("X") : to_string(t[i]));
    return s;
}

int main() {
    vector<int> keys = {89, 18, 49, 58, 69};
    for (string mode : {"linear", "quadratic", "double"}) {
        vector<int> t(10, EMPTY);
        string ps;
        int total = 0;
        for (size_t i = 0; i < keys.size(); i++) { int p = insertKey(t, keys[i], mode); total += p; ps += (i ? ", " : "") + to_string(p); }
        printf("%-9s m=10: %s   probes [%s] total %d\n", mode.c_str(), show(t).c_str(), ps.c_str(), total);
    }
    vector<int> t(10, EMPTY);
    for (int k : keys) insertKey(t, k, "linear");
    t[search(t, 49, "linear")] = DELETED;
    printf("linear, after deleting 49: %s\n", show(t).c_str());
    printf("search 58 -> %d | search 49 -> %d\n", search(t, 58, "linear"), search(t, 49, "linear"));
    int p = insertKey(t, 79, "linear");
    printf("insert 79 uses %d probes: %s\n", p, show(t).c_str());
    int m = 5, n = 0;
    vector<int> table(m, EMPTY);
    for (int k : {12, 7, 3, 18, 25}) {
        if ((n + 1) / (double)m > 0.7) {
            vector<int> old;
            for (int x : table) if (x != EMPTY) old.push_back(x);
            m = 11;
            table.assign(m, EMPTY);
            for (int x : old) insertKey(table, x, "linear");
            printf("load would exceed 0.7 -> rehash to m=%d: %s\n", m, show(table).c_str());
        }
        insertKey(table, k, "linear");
        n++;
    }
    printf("final m=%d, n=%d, load factor = %.2f: %s\n", m, n, n / (double)m, show(table).c_str());
}

Java · OpenAddressing.java

// Lecture 11: open addressing (linear, quadratic, double hashing), deletion, rehashing.
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class OpenAddressing {
    static final int EMPTY = -1, DELETED = -2;   // keys are non-negative

    static int probe(int key, int i, int m, String mode) {
        int h = key % m;
        if (mode.equals("linear")) return (h + i) % m;
        if (mode.equals("quadratic")) return (h + i * i) % m;
        return (h + i * (7 - key % 7)) % m;      // double hashing, h2(k) = 7 - (k mod 7)
    }

    static int insert(int[] t, int key, String mode) {   // returns probes used, -1 if full
        for (int i = 0; i < t.length; i++) {
            int j = probe(key, i, t.length, mode);
            if (t[j] == EMPTY || t[j] == DELETED) { t[j] = key; return i + 1; }
        }
        return -1;
    }

    static int search(int[] t, int key, String mode) {
        for (int i = 0; i < t.length; i++) {
            int j = probe(key, i, t.length, mode);
            if (t[j] == EMPTY) return -1;            // an empty slot ends the search
            if (t[j] == key) return j;               // a DELETED slot does not
        }
        return -1;
    }

    static String show(int[] t) {
        StringBuilder s = new StringBuilder();
        for (int i = 0; i < t.length; i++) s.append(i > 0 ? " " : "").append(t[i] == EMPTY ? "." : t[i] == DELETED ? "X" : String.valueOf(t[i]));
        return s.toString();
    }

    public static void main(String[] args) {
        int[] keys = {89, 18, 49, 58, 69};
        for (String mode : new String[]{"linear", "quadratic", "double"}) {
            int[] t = new int[10];
            Arrays.fill(t, EMPTY);
            List<Integer> ps = new ArrayList<>();
            int total = 0;
            for (int k : keys) { int p = insert(t, k, mode); ps.add(p); total += p; }
            System.out.printf("%-9s m=10: %s   probes %s total %d%n", mode, show(t), ps, total);
        }
        int[] t = new int[10];
        Arrays.fill(t, EMPTY);
        for (int k : keys) insert(t, k, "linear");
        t[search(t, 49, "linear")] = DELETED;
        System.out.println("linear, after deleting 49: " + show(t));
        System.out.println("search 58 -> " + search(t, 58, "linear") + " | search 49 -> " + search(t, 49, "linear"));
        int p = insert(t, 79, "linear");
        System.out.println("insert 79 uses " + p + " probes: " + show(t));
        int m = 5, n = 0;
        int[] table = new int[m];
        Arrays.fill(table, EMPTY);
        for (int k : new int[]{12, 7, 3, 18, 25}) {
            if ((n + 1) / (double) m > 0.7) {
                List<Integer> old = new ArrayList<>();
                for (int x : table) if (x != EMPTY) old.add(x);
                m = 11;
                table = new int[m];
                Arrays.fill(table, EMPTY);
                for (int x : old) insert(table, x, "linear");
                System.out.println("load would exceed 0.7 -> rehash to m=" + m + ": " + show(table));
            }
            insert(table, k, "linear");
            n++;
        }
        System.out.printf("final m=%d, n=%d, load factor = %.2f: %s%n", m, n, n / (double) m, show(table));
    }
}

Each operation follows one probe sequence: expected O(1/(1 − α)) probes, worst case O(m). Rehashing is O(n) but amortised O(1) per insertion. Copy and run it locally; this website shows code but does not execute it.

  • EMPTY and DELETED are distinct markers (−1 and −2 in C++/Java, None and "DEL" in Python); search stops only at EMPTY.
  • This demo’s insert does not first check whether the key already exists further along the sequence; a production table searches first to avoid duplicates.

Common confusions

ConfusionCorrection
“Open addressing and open hashing are the same.”Open hashing usually means chaining; open addressing (closed hashing) stores keys in the array.
“Delete by emptying the slot.”That breaks later searches; use a tombstone.
“Quadratic probing always finds a slot.”Only with prime m and α ≤ ½.
“h₂ can be any hash function.”It must be non-zero and coprime with m.
“Rehash = copy the array.”Every key must be re-hashed with the new size.
