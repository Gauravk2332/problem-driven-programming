Greedy method

Build a solution in steps; at each step take the best feasible candidate by a fixed rule; never undo a choice. Usually sort + one pass.

solution = ∅
repeat: x = Select(candidates)
  if Feasible(solution ∪ {x}): add x
until solution complete

Components

Candidate set · selection function · feasibility check · objective · solution check.

Why greedy can be correct

Greedy-choice
some optimal solution contains the first greedy choice
Optimal substructure
greedy choice + optimal solution of the remainder is optimal

Both ⇒ induction ⇒ greedy optimal. Substructure alone is not enough (DP has it too).

Worked example

₹289, coins 1,2,5,10,20,50,100: 100+100+50+20+10+5+2+2 = 8 (optimal; rupees are canonical).

Exchange proof for {1,2,5,10}

In an optimal solution: ≤ one 1; ≤ two 2s; not 1 with two 2s (→5); ≤ one 5 (5+5→10). So coins <10 total ≤ 9 ⇒ exactly ⌊A/10⌋ tens, as greedy takes. Repeat for the remainder.

Common mistakes · full marks

  • Examples that pass are not a proof.
  • Greedy rule ≠ “largest”; it is problem-specific.
  • Without coin 1, greedy can get stuck.

Full marks: define, state both properties, trace, then prove (exchange) or refute (counterexample), and give complexity.

Two-mark self-test

  1. Define the greedy method.
    A design technique that builds a solution step by step, at each step making the locally best feasible choice by a fixed rule and never revising it.
  2. State the greedy-choice property.
    There exists an optimal solution that contains the first choice made by the greedy rule; so the greedy choice can be made without losing optimality.
  3. State the optimal substructure property.
    An optimal solution contains optimal solutions to its subproblems: after the first choice, the rest is an optimal solution of the remaining instance.
  4. Give a coin system and amount where largest-first is not optimal.
    Coins {1,3,4}, amount 6: greedy 4+1+1 (3 coins), optimum 3+3 (2 coins).
  5. List the five components of a greedy algorithm.
    Candidate set, selection function, feasibility check, objective function, solution check.
