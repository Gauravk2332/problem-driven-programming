Understand the greedy rule

Design a greedy algorithm by stating the objective and feasibility, proposing a priority rule, proving the choice is safe, repeating on the residual instance and analysing costs. Here goods are divisible; choose the greatest value per unit weight, not greatest total value or lowest weight.

ratio = value / weight
take = min(remaining capacity, item weight)
gain = take × ratio

Total 240. In an optimal packing, if lower-ratio material occupies capacity while higher-ratio material remains, swap equal weights. Value cannot decrease. Repeating establishes an optimum with each higher ratio exhausted before a lower one. Assumptions: weights positive, values nonnegative, fractions allowed.

For whole items only, the same rule takes A+B =160; optimum B+C=220. Use 0/1 knapsack DP for that version.

Chapter 04 / 07

Implement and analyse

def fractional(items, capacity):
    value=0.0
    for w,v in sorted(items,key=lambda p:p[1]/p[0],reverse=True):
        take=min(capacity,w)
        value+=take*v/w
        capacity-=take
    return value
print(fractional([(10,60),(20,100),(30,120)],50))
