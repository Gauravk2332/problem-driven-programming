Chapter 01 / 11

Recall: rules must be tested, then proved

Lecture 13 gave a design process: model the problem, propose rules, refute the wrong ones with counterexamples, and prove the survivor. Today the problem has four natural rules, and three of them are wrong in instructive ways.

We write an activity as a half-open interval [s, f): it occupies the hall from time s up to, but not including, time f. Two activities are compatible if they do not overlap, so [1, 4) and [4, 7) are compatible: one ends exactly when the next begins.

Are [2, 5) and [5, 8) compatible?

Chapter 06 / 11

Proof: greedy stays ahead

Claim: earliest-finish-first selects a maximum set

Let the greedy choices be g₁, g₂, …, gₖ and an optimal solution be o₁, o₂, …, oₘ, both listed by finish time, with m ≥ k. Write f(x) for the finish of x.

Lemma (greedy stays ahead). For every r ≤ k, f(gᵣ) ≤ f(oᵣ).

  • Base r = 1: greedy picks the activity with the earliest finish of all, so f(g₁) ≤ f(o₁).
  • Step: assume f(gᵣ) ≤ f(oᵣ). Since o_{r+1} starts after oᵣ ends, s(o_{r+1}) ≥ f(oᵣ) ≥ f(gᵣ), so o_{r+1} is compatible with gᵣ and was available to greedy. Greedy chose the compatible activity with the earliest finish, so f(g_{r+1}) ≤ f(o_{r+1}).

Conclusion. If m > k, then o_{k+1} starts after f(oₖ) ≥ f(gₖ), so it was still available when greedy stopped, but greedy only stops when nothing compatible remains. Contradiction. Hence k = m.

An equivalent exchange view: replace o₁ by g₁ in the optimal solution. Since g₁ finishes no later, everything after o₁ is still compatible, so the solution stays feasible and the same size. Then repeat on the activities that start after f(g₁): optimal substructure.

Chapter 07 / 11

From the rule to code

Sort by finish time, then one scan with a single variable. The test s >= last_finish encodes the half-open convention.

Python · activity_selection.py

# Activity selection: maximum number of compatible half-open intervals [s, f) (Lecture 14)


def select_activities(acts):
    """acts: list of (name, start, finish) with start < finish. Earliest finish first."""
    chosen, last_finish = [], float("-inf")
    for name, s, f in sorted(acts, key=lambda a: a[2]):   # stable sort by finish
        if s >= last_finish:          # compatible with everything chosen so far
            chosen.append(name)
            last_finish = f
    return chosen


if __name__ == "__main__":
    s = [1, 3, 0, 5, 3, 5, 6, 8, 8, 2, 12]
    f = [4, 5, 6, 7, 9, 9, 10, 11, 12, 14, 16]
    acts = [(f"a{i + 1}", s[i], f[i]) for i in range(len(s))]
    chosen = select_activities(acts)
    print("selected:", " ".join(chosen), f"({len(chosen)} activities)")
    print("fewest removals for no overlap:", len(acts) - len(chosen))
    print("touching [1,4) and [4,7):", " ".join(select_activities([("x", 1, 4), ("y", 4, 7)])))
    print("empty input:", len(select_activities([])))

C++ · activity_selection.cpp

// Activity selection: maximum number of compatible half-open intervals [s, f) (Lecture 14)
#include <algorithm>
#include <climits>
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct Act { string name; int s, f; };   // start < finish

vector<string> selectActivities(vector<Act> acts) {
    stable_sort(acts.begin(), acts.end(), [](const Act& a, const Act& b) { return a.f < b.f; });
    vector<string> chosen;
    long long lastFinish = LLONG_MIN;
    for (const Act& a : acts)
        if (a.s >= lastFinish) {          // compatible with everything chosen so far
            chosen.push_back(a.name);
            lastFinish = a.f;
        }
    return chosen;
}

string join(const vector<string>& v) {
    string s;
    for (size_t i = 0; i < v.size(); i++) s += (i ? " " : "") + v[i];
    return s;
}

int main() {
    vector<int> s = {1, 3, 0, 5, 3, 5, 6, 8, 8, 2, 12};
    vector<int> f = {4, 5, 6, 7, 9, 9, 10, 11, 12, 14, 16};
    vector<Act> acts;
    for (size_t i = 0; i < s.size(); i++) acts.push_back({"a" + to_string(i + 1), s[i], f[i]});
    vector<string> chosen = selectActivities(acts);
    cout << "selected: " << join(chosen) << " (" << chosen.size() << " activities)\n";
    cout << "fewest removals for no overlap: " << acts.size() - chosen.size() << "\n";
    cout << "touching [1,4) and [4,7): " << join(selectActivities({{"x", 1, 4}, {"y", 4, 7}})) << "\n";
    cout << "empty input: " << selectActivities({}).size() << "\n";
}

Java · ActivitySelection.java

// Activity selection: maximum number of compatible half-open intervals [s, f) (Lecture 14)
import java.util.*;

public class ActivitySelection {
    record Act(String name, int s, int f) {}   // start < finish

    static List<String> select(List<Act> acts) {
        List<Act> order = new ArrayList<>(acts);
        order.sort(Comparator.comparingInt(Act::f));   // stable sort by finish
        List<String> chosen = new ArrayList<>();
        long lastFinish = Long.MIN_VALUE;
        for (Act a : order)
            if (a.s() >= lastFinish) {      // compatible with everything chosen so far
                chosen.add(a.name());
                lastFinish = a.f();
            }
        return chosen;
    }

    public static void main(String[] args) {
        int[] s = {1, 3, 0, 5, 3, 5, 6, 8, 8, 2, 12};
        int[] f = {4, 5, 6, 7, 9, 9, 10, 11, 12, 14, 16};
        List<Act> acts = new ArrayList<>();
        for (int i = 0; i < s.length; i++) acts.add(new Act("a" + (i + 1), s[i], f[i]));
        List<String> chosen = select(acts);
        System.out.println("selected: " + String.join(" ", chosen) + " (" + chosen.size() + " activities)");
        System.out.println("fewest removals for no overlap: " + (acts.size() - chosen.size()));
        System.out.println("touching [1,4) and [4,7): " + String.join(" ",
                select(List.of(new Act("x", 1, 4), new Act("y", 4, 7)))));
        System.out.println("empty input: " + select(List.of()).size());
    }
}

Output (identical in all three languages):

selected: a1 a4 a8 a11 (4 activities)
fewest removals for no overlap: 7
touching [1,4) and [4,7): x y
empty input: 0

Time O(n log n) for the sort and O(n) for the scan; extra space O(n) for the sorted copy (O(1) besides that if only counting). Copy and run it locally; this website shows code but does not execute it.

  • Closed intervals [s, f] (endpoints touching counts as overlap): use s > last_finish.
  • Ties in finish time: any order works; the proof never relied on breaking ties.
  • Removals: the fewest activities to remove so that none overlap is n − (maximum selected); here 11 − 4 = 7.

Weighted warning. With rewards [0,10) worth 100 and [1,3), [4,6) worth 1 each, earliest finish takes the two short ones (reward 2), but the single long activity is worth 100. Counting activities and summing rewards are different problems.

Medium answers 5 marks each

B1 · Apply the greedy algorithm to s = (1,3,0,5,3,5,6,8,8,2,12), f = (4,5,6,7,9,9,10,11,12,14,16). 5 marks

Reveal model answer
Already sorted by finish. Take a1 (last 4); skip a2, a3; take a4 (7); skip a5, a6, a7; take a8 (11); skip a9, a10; take a11 (16). Result {a1, a4, a8, a11}, size 4.

Sorting 1; trace 3; answer 1.

B2 · Refute 'earliest start first' and 'shortest first', and explain why earliest finish avoids both failures. 5 marks

Reveal model answer
Earliest start: [0,10), [1,3), [4,6) → 1 vs 2. Shortest: [0,5), [4,7), [6,11) → 1 vs 2. Earliest finish leaves the most remaining time after each choice, which is exactly what the stays-ahead lemma formalises.

Two counterexamples 2+2; explanation 1.

B3 · Prove the greedy-choice property for activity selection by an exchange argument. 5 marks

Reveal model answer
Let a be the activity with earliest finish and O an optimal set with first activity o. f(a) ≤ f(o), so O − {o} ∪ {a} is compatible and the same size, hence optimal and contains a. The rest is the same problem on activities starting at or after f(a).

Setup 1; exchange 2; size/feasibility 1; substructure 1.

C2 · Compare activity selection, fewest removals, interval partitioning and weighted interval scheduling: objective, method and complexity. 10 marks

Reveal model answer
Max count: earliest finish, O(n log n). Removals: n − max. Partitioning: sort by start + min-heap of finish times, rooms = depth, O(n log n). Weighted: sort by finish, p(i) by binary search, dp[i] = max(dp[i−1], wᵢ + dp[p(i)]), O(n log n); greedy fails (example).
