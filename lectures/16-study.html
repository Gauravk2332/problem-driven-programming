Chapter 02 / 07

Understand the greedy rule

A priority queue repeatedly returns an element with smallest (min-heap) or largest priority (max-heap). Unlike a sorted static list, new merged values arrive after each step. A binary min-heap gives O(1) peek, O(log n) insertion and extraction; heap construction from an array can be O(n).

Why two smallest? A merge order forms a full binary tree; each file weight is paid once per ancestor. At a deepest sibling pair, swapping in the two smallest weights cannot increase weighted depth. Contract those siblings to a single node with summed weight and solve the smaller optimal problem. Induction proves the choice. Huffman coding uses the same argument with symbol frequencies to minimize weighted prefix-code length; left/right labels may differ under ties.

Empty or singleton input has merge cost zero. Costs must be nonnegative.

import heapq
def merge_cost(a):
    h=list(a);heapq.heapify(h);total=0
    while len(h)>1:
        x=heapq.heappop(h)+heapq.heappop(h)
        total+=x;heapq.heappush(h,x)
    return total
print(merge_cost([5,10,20,30]))

n−1 merges, two extractions and one insertion each. O(n log n) time and O(n) heap space. Check sums for overflow. For Huffman, store left/right children when merging; one-symbol alphabets need an explicit coding convention.
