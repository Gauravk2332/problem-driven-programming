Chapter 01 / 12

Recall: two proof tools

You have now seen two ways to prove a greedy algorithm correct:

  • Exchange argument: take any optimal solution and swap parts toward the greedy one without making it worse (fractional knapsack, job sequencing, Huffman).
  • Greedy stays ahead: show that after every step greedy is at least as well placed as any optimum (activity selection).

Today adds a third: a lower bound. If you can prove that every solution needs at least k resources, and greedy uses exactly k, greedy is optimal.

Chapter 02 / 12

Three print jobs, one printer

Three students send print jobs at the same moment: A needs 6 minutes, B 2 minutes, C 4 minutes. The printer runs one job at a time. A student's completion time is when their job finishes. We want the sum of completion times to be as small as possible (equivalently, the average).

OrderCompletion timesSum
A, B, C6, 8, 1226
B, C, A2, 6, 1220
C, B, A4, 6, 1222
Think first

The last job always finishes at 12. Why does the order still matter?

Answer
The sum counts every student's finish time. A long job placed early delays every job after it, so its length is counted many times. Shortest first counts long jobs the fewest times.

Chapter 03 / 12

Shortest processing time first (SPT)

Rule. Run jobs in non-decreasing order of processing time.

Why it works: in the order j₁, j₂, …, jₙ the k-th job's length tⱼₖ appears in the completion time of itself and every later job, so

Σ completion times = n·t₁ + (n−1)·t₂ + … + 2·tₙ₋₁ + 1·tₙ

The largest multiplier should go with the smallest length: exactly SPT.

Exchange proof (adjacent swap)

Suppose an order has adjacent jobs x then y with tₓ > tᵧ, both starting after time T. Their completion times sum to (T + tₓ) + (T + tₓ + tᵧ). Swapping gives (T + tᵧ) + (T + tᵧ + tₓ). The difference is tₓ − tᵧ > 0, and no other job's completion time changes.

So any order with an "inversion" (a longer job directly before a shorter one) can be improved. An optimal order therefore has no inversions: it is SPT.

Waiting time (time before a job starts) is completion minus length, so SPT also minimises total and average waiting time. In operating systems this is the non-preemptive shortest-job-first policy when all jobs arrive together.

Optional: jobs with weights (Smith's rule)

If job i has importance wᵢ > 0 and we minimise Σ wᵢ·Cᵢ, order jobs by increasing tᵢ / wᵢ. The same adjacent-swap argument gives the condition tₓ·wᵧ ≤ tᵧ·wₓ. With all weights 1 this is SPT.

Every lecture needs a room

A department has eight lectures today (times in hours). Every lecture must be held; two lectures cannot share a room at the same time. What is the fewest number of rooms?

LectureABCDEFGH
Time[9, 11)[9, 13)[9, 11)[11, 14)[11, 13)[13, 15)[14, 16)[14, 16)
Think first

At 9 o'clock, how many lectures are running? What does that tell you about the number of rooms?

A lower bound
A, B and C all run at 9:00, so at least 3 rooms are needed whatever we do. The maximum number of intervals alive at one moment is called the depth. Every schedule needs at least depth rooms.

Greedy rule (interval partitioning). Go through lectures by start time. If some room is already free when the lecture starts, use it; otherwise open a new room. A min-heap of room finish times tells us, in O(log n), whether the earliest-free room is free yet.

sort lectures by start
heap = empty  // (finish time, room)
for each lecture [s, f):
  if heap not empty and heap.min.finish ≤ s: room = pop
  else: room = new room
  push (f, room)

Chapter 07 / 12

Why the room greedy is optimal

Lower-bound argument

Suppose the greedy opens a new room, room k, for a lecture starting at time s. It does so only because all k − 1 existing rooms are busy at time s: each holds a lecture that started at or before s (we process by start time) and finishes after s.

So at time s there are k lectures running at once: those k − 1 plus the new one. Hence the depth is at least k, and every schedule needs at least k rooms.

The last room greedy opens therefore matches the lower bound: greedy uses exactly depth rooms, which is optimal.

Note that sorting by start time is essential here. Sorting by finish time works for selecting a maximum set of activities in one room (Lecture 14), but for partitioning all of them it can waste rooms.

Python · scheduling.py

# Greedy scheduling: shortest processing time and interval partitioning (Lecture 17)
import heapq


def spt(tasks):
    """tasks: (name, duration > 0), all ready at time 0. Returns order, completions, sum."""
    order = sorted(tasks, key=lambda t: t[1])     # shortest first (stable for ties)
    time, completions = 0, []
    for _, d in order:
        time += d
        completions.append(time)
    return [n for n, _ in order], completions, sum(completions)


def min_rooms(intervals):
    """intervals: (name, start, finish), half-open. Returns {name: room}, rooms used."""
    free_at = []                                   # heap of (finish time, room number)
    room_of, rooms = {}, 0
    for name, s, f in sorted(intervals, key=lambda x: x[1]):   # by start time
        if free_at and free_at[0][0] <= s:         # earliest-finishing room is free
            _, r = heapq.heappop(free_at)
        else:                                      # every room is busy at time s
            rooms += 1
            r = rooms
        room_of[name] = r
        heapq.heappush(free_at, (f, r))
    return room_of, rooms


if __name__ == "__main__":
    order, comp, total = spt([("A", 6), ("B", 2), ("C", 4)])
    print("SPT order", " ".join(order), "| completions", " ".join(map(str, comp)), "| total", total)
    lectures = [("A", 9, 11), ("B", 9, 13), ("C", 9, 11), ("D", 11, 14),
                ("E", 11, 13), ("F", 13, 15), ("G", 14, 16), ("H", 14, 16)]
    room_of, rooms = min_rooms(lectures)
    print(" ".join(f"{n}:R{room_of[n]}" for n, _, _ in lectures), f"| rooms {rooms}")

C++ · scheduling.cpp

// Greedy scheduling: shortest processing time and interval partitioning (Lecture 17)
#include <algorithm>
#include <functional>
#include <iostream>
#include <map>
#include <queue>
#include <string>
#include <utility>
#include <vector>
using namespace std;

struct Task { string name; long long d; };            // duration > 0, ready at time 0
struct Interval { string name; long long s, f; };     // half-open [s, f)

long long spt(vector<Task> tasks, string& order, string& completions) {
    stable_sort(tasks.begin(), tasks.end(), [](const Task& a, const Task& b) { return a.d < b.d; });
    long long time = 0, total = 0;
    order.clear(); completions.clear();
    for (auto& t : tasks) {
        time += t.d;
        total += time;
        order += (order.empty() ? "" : " ") + t.name;
        completions += (completions.empty() ? "" : " ") + to_string(time);
    }
    return total;
}

int minRooms(vector<Interval> v, map<string, int>& roomOf) {
    stable_sort(v.begin(), v.end(), [](const Interval& a, const Interval& b) { return a.s < b.s; });
    // min-heap of (finish time, room number)
    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> freeAt;
    int rooms = 0;
    for (auto& x : v) {
        int r;
        if (!freeAt.empty() && freeAt.top().first <= x.s) { r = freeAt.top().second; freeAt.pop(); }
        else r = ++rooms;                              // every room is busy at time s
        roomOf[x.name] = r;
        freeAt.push({x.f, r});
    }
    return rooms;
}

int main() {
    string order, comp;
    long long total = spt({{"A", 6}, {"B", 2}, {"C", 4}}, order, comp);
    cout << "SPT order " << order << " | completions " << comp << " | total " << total << "\n";
    vector<Interval> lectures = {{"A", 9, 11}, {"B", 9, 13}, {"C", 9, 11}, {"D", 11, 14},
                                 {"E", 11, 13}, {"F", 13, 15}, {"G", 14, 16}, {"H", 14, 16}};
    map<string, int> roomOf;
    int rooms = minRooms(lectures, roomOf);
    for (auto& x : lectures) cout << x.name << ":R" << roomOf[x.name] << " ";
    cout << "| rooms " << rooms << "\n";
}

Java · Scheduling.java

// Greedy scheduling: shortest processing time and interval partitioning (Lecture 17)
import java.util.*;

public class Scheduling {
    record Task(String name, long d) {}                // duration > 0, ready at time 0
    record Interval(String name, long s, long f) {}    // half-open [s, f)

    static long spt(List<Task> tasks, StringJoiner order, StringJoiner completions) {
        List<Task> sorted = new ArrayList<>(tasks);
        sorted.sort(Comparator.comparingLong(Task::d));   // stable: ties keep input order
        long time = 0, total = 0;
        for (Task t : sorted) {
            time += t.d();
            total += time;
            order.add(t.name());
            completions.add(String.valueOf(time));
        }
        return total;
    }

    static int minRooms(List<Interval> v, Map<String, Integer> roomOf) {
        List<Interval> sorted = new ArrayList<>(v);
        sorted.sort(Comparator.comparingLong(Interval::s));
        // min-heap of {finish time, room number}
        PriorityQueue<long[]> freeAt = new PriorityQueue<>((a, b) ->
                a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]));
        int rooms = 0;
        for (Interval x : sorted) {
            int r;
            if (!freeAt.isEmpty() && freeAt.peek()[0] <= x.s()) r = (int) freeAt.poll()[1];
            else r = ++rooms;                          // every room is busy at time s
            roomOf.put(x.name(), r);
            freeAt.add(new long[]{x.f(), r});
        }
        return rooms;
    }

    public static void main(String[] args) {
        StringJoiner order = new StringJoiner(" "), comp = new StringJoiner(" ");
        long total = spt(List.of(new Task("A", 6), new Task("B", 2), new Task("C", 4)), order, comp);
        System.out.println("SPT order " + order + " | completions " + comp + " | total " + total);
        List<Interval> lectures = List.of(new Interval("A", 9, 11), new Interval("B", 9, 13),
                new Interval("C", 9, 11), new Interval("D", 11, 14), new Interval("E", 11, 13),
                new Interval("F", 13, 15), new Interval("G", 14, 16), new Interval("H", 14, 16));
        Map<String, Integer> roomOf = new HashMap<>();
        int rooms = minRooms(lectures, roomOf);
        StringBuilder out = new StringBuilder();
        for (Interval x : lectures) out.append(x.name()).append(":R").append(roomOf.get(x.name())).append(" ");
        System.out.println(out + "| rooms " + rooms);
    }
}

SPT: O(n log n) sort + O(n) scan. Rooms: O(n log n) sort + n heap operations of O(log n); heap size ≤ number of rooms ≤ n. Copy and run it locally; this website shows code but does not execute it.

  • Half-open times: a room is reusable when its finish ≤ the new start. For closed intervals use <.
  • Only the count needed? A sweep over sorted start and end times (two pointers) gives the depth without room numbers.
  • Overflow: completion-time sums grow like n² · max length; use 64-bit integers.
