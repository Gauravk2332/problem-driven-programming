Chapter 02 / 07

Understand the greedy rule

For unweighted completion-time minimization, sort nondecreasing durations (SPT). If two adjacent tasks of lengths x>y start after t, their completion sum is 2t+2x+y; swapping gives 2t+2y+x, improving by x−y. Other completion times unchanged. Repeatedly remove inversions. The same order minimizes total waiting time when all arrive together. For weighted completion time, compare processing time/weight (positive weights); different release times or preemption require separate reasoning.

Chapter 03 / 07

Work through the choices

Another scheduling objective: allocate the minimum rooms to all intervals (half-open). Sort by starts. Maintain min-heap of room finish times. If earliest finish ≤ new start, reuse that room; otherwise add one. If a room must be added, all existing rooms overlap the new start; that simultaneous overlap is a lower bound. Therefore optimal.

Chapter 04 / 07

Implement and analyse

import heapq
def rooms(a):
    h=[]
    for s,f in sorted(a):
        if h and h[0]<=s:heapq.heappop(h)
        heapq.heappush(h,f)
    return len(h)
print(rooms([(1,4),(2,5),(4,6),(5,7)]))

Heap stores one finish per allocated room, including currently free rooms. Its size equals total rooms (never decreases across jobs). Empty list returns 0. Both SPT and room allocation sort in O(n log n); heap space O(n) worst case, SPT scan O(n). Practice: CSES Room Allocation uses inclusive dates and requires recording room IDs; adapt the comparison and heap entries.
