Connect seven offices as cheaply as possible

A company must connect seven offices A–G with fibre so that every office can reach every other (possibly through others). The possible links and their costs (in lakh ₹) are:

LinkABADBCBDBECEDEDFEFEGFG
Cost7589751568911
Think first

How many links does a cheapest network need? Which link would you buy first?

Answer
A network connecting 7 offices with no wasted links is a spanning tree with exactly 6 links (any extra link creates a cycle, which can be removed). The cheapest such tree is a minimum spanning tree (MST). A natural greedy idea: buy the cheapest link that does not create a cycle, and repeat. Its cost here is 39.

Chapter 03 / 12

Kruskal's algorithm

Rule. Consider edges in non-decreasing weight. Accept an edge if it joins two different components; reject it if both ends are already connected (it would close a cycle). Stop after V − 1 accepted edges.

sort edges by weight
each vertex starts in its own component
for each edge (u, v, w):
  if find(u) ≠ find(v): accept; union(u, v)
  else: reject   // would close a cycle

A disjoint-set union (DSU) structure answers "same component?" almost in constant time: find follows parent pointers to a representative, and union links two representatives (smaller tree under larger, with path compression).

Chapter 06 / 12

Why Kruskal is correct: the cut property

Cut property

A cut splits the vertices into two non-empty sets S and V − S. If e is a minimum-weight edge crossing the cut, then some MST contains e.

Proof (exchange). Let T be an MST not containing e = (u, v). Adding e to T creates a cycle. The cycle goes from u's side to v's side and must come back, so it contains another edge f that crosses the cut. Since e is lightest across the cut, w(e) ≤ w(f). Then T − f + e is a spanning tree of weight ≤ w(T), so it is also an MST, and it contains e.

Applying it to Kruskal. When Kruskal accepts e = (u, v), let S be u's current component. Every lighter edge has already been examined: each one is inside some component or was rejected, so none crosses from S to the outside. Hence e is a lightest edge crossing the cut (S, V − S), and by the cut property it is safe. By induction, all accepted edges belong to one MST.

The same property justifies Prim's algorithm, which grows a single tree and repeatedly adds the cheapest edge leaving it (a heap holds the candidate edges).

Chapter 07 / 12

When greedy fails: finding counterexamples

A plausible greedy rule is a hypothesis. Disprove it quickly before trying to prove it.

  1. Try tiny cases: 2–3 items with extreme values (one huge, one tiny; ties; touching endpoints).
  2. Ask what the rule ignores: value ignores weight; start time ignores length; shortest ignores position.
  3. Stress-test: write a brute-force solver, run both on thousands of random small inputs, stop at the first disagreement.

The gap is unbounded. Some greedy algorithms are still useful as approximations with a proven guarantee, but that is beyond this module.

Performance analysis of greedy algorithms

Greedy algorithms are usually fast because they make one pass of decisions. The cost is dominated by the data structure that supplies the next choice.

Python · kruskal.py

# Kruskal's minimum spanning tree with disjoint-set union (Lecture 18)


def kruskal(vertices, edges):
    """edges: (weight, u, v) for an undirected graph. Returns (tree edges, cost, connected)."""
    parent = {v: v for v in vertices}
    size = {v: 1 for v in vertices}

    def find(x):                                  # root of x, with path halving
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    tree, cost = [], 0
    for w, u, v in sorted(edges, key=lambda e: e[0]):   # stable: ties keep input order
        ru, rv = find(u), find(v)
        if ru == rv:
            continue                              # would close a cycle
        if size[ru] < size[rv]:
            ru, rv = rv, ru
        parent[rv] = ru                           # union by size
        size[ru] += size[rv]
        tree.append(f"{u}{v}({w})")
        cost += w
    return tree, cost, len(tree) == len(vertices) - 1


if __name__ == "__main__":
    V = "ABCDEFG"
    E = [(7, "A", "B"), (5, "A", "D"), (8, "B", "C"), (9, "B", "D"), (7, "B", "E"),
         (5, "C", "E"), (15, "D", "E"), (6, "D", "F"), (8, "E", "F"), (9, "E", "G"),
         (11, "F", "G")]
    tree, cost, ok = kruskal(V, E)

C++ · kruskal.cpp

// Kruskal's minimum spanning tree with disjoint-set union (Lecture 18)
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <vector>
using namespace std;

struct Edge { long long w; char u, v; };   // undirected

struct DSU {
    vector<int> parent, size;
    explicit DSU(int n) : parent(n), size(n, 1) { iota(parent.begin(), parent.end(), 0); }
    int find(int x) {                       // root of x, with path halving
        while (parent[x] != x) x = parent[x] = parent[parent[x]];
        return x;
    }
    bool unite(int a, int b) {              // false if a and b are already connected
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a, b);  // union by size
        parent[b] = a; size[a] += size[b];
        return true;
    }
};

long long kruskal(const string& vertices, vector<Edge> edges, string& tree, bool& connected) {
    stable_sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    DSU dsu(vertices.size());
    long long cost = 0;
    size_t used = 0;
    tree.clear();
    for (auto& e : edges)
        if (dsu.unite(vertices.find(e.u), vertices.find(e.v))) {   // skip edges that close a cycle
            tree += (tree.empty() ? "" : " ") + string{e.u, e.v} + "(" + to_string(e.w) + ")";
            cost += e.w;
            used++;
        }
    connected = used + 1 == vertices.size();
    return cost;
}

int main() {
    vector<Edge> E = {{7, 'A', 'B'}, {5, 'A', 'D'}, {8, 'B', 'C'}, {9, 'B', 'D'}, {7, 'B', 'E'},
                      {5, 'C', 'E'}, {15, 'D', 'E'}, {6, 'D', 'F'}, {8, 'E', 'F'}, {9, 'E', 'G'},
                      {11, 'F', 'G'}};
    string tree;
    bool ok;
    long long cost = kruskal("ABCDEFG", E, tree, ok);
    cout << "MST: " << tree << " | cost " << cost << " | connected " << (ok ? "True" : "False") << "\n";
    cost = kruskal("ABC", {{1, 'A', 'B'}}, tree, ok);
    cout << "MST: " << tree << " | cost " << cost << " | connected " << (ok ? "True" : "False") << "\n";
}

Java · Kruskal.java

// Kruskal's minimum spanning tree with disjoint-set union (Lecture 18)
import java.util.*;

public class Kruskal {
    record Edge(long w, char u, char v) {}   // undirected

    static int[] parent, size;

    static int find(int x) {                 // root of x, with path halving
        while (parent[x] != x) x = parent[x] = parent[parent[x]];
        return x;
    }

    static boolean unite(int a, int b) {     // false if a and b are already connected
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) { int t = a; a = b; b = t; }   // union by size
        parent[b] = a; size[a] += size[b];
        return true;
    }

    static long kruskal(String vertices, List<Edge> edges, StringJoiner tree, boolean[] connected) {
        int n = vertices.length();
        parent = new int[n]; size = new int[n];
        for (int i = 0; i < n; i++) { parent[i] = i; size[i] = 1; }
        List<Edge> sorted = new ArrayList<>(edges);
        sorted.sort(Comparator.comparingLong(Edge::w));      // stable: ties keep input order
        long cost = 0;
        int used = 0;
        for (Edge e : sorted)
            if (unite(vertices.indexOf(e.u()), vertices.indexOf(e.v()))) {   // skip cycle edges
                tree.add("" + e.u() + e.v() + "(" + e.w() + ")");
                cost += e.w();
                used++;
            }
        connected[0] = used == n - 1;
        return cost;
    }

    public static void main(String[] args) {
        List<Edge> E = List.of(new Edge(7, 'A', 'B'), new Edge(5, 'A', 'D'), new Edge(8, 'B', 'C'),
                new Edge(9, 'B', 'D'), new Edge(7, 'B', 'E'), new Edge(5, 'C', 'E'), new Edge(15, 'D', 'E'),
                new Edge(6, 'D', 'F'), new Edge(8, 'E', 'F'), new Edge(9, 'E', 'G'), new Edge(11, 'F', 'G'));
        boolean[] ok = new boolean[1];
        StringJoiner tree = new StringJoiner(" ");
        long cost = kruskal("ABCDEFG", E, tree, ok);
        System.out.println("MST: " + tree + " | cost " + cost + " | connected " + (ok[0] ? "True" : "False"));
        tree = new StringJoiner(" ");
        cost = kruskal("ABC", List.of(new Edge(1, 'A', 'B')), tree, ok);
        System.out.println("MST: " + tree + " | cost " + cost + " | connected " + (ok[0] ? "True" : "False"));
    }
}

MST: AD(5) CE(5) DF(6) AB(7) BE(7) EG(9) | cost 39 | connected True

Time O(E log E) for sorting plus O(E·α(V)) for DSU operations, where α grows so slowly it is below 5 in practice; extra space O(V). Copy and run it locally; this website shows code but does not execute it.

  • Disconnected graphs have no spanning tree; Kruskal then returns a minimum spanning forest. Check that V − 1 edges were accepted, as the program does.
  • Negative weights are fine for MSTs (only the order matters), unlike Dijkstra.
  • Ties: different tie orders can give different trees of the same minimum cost.

B2 · Prove the cut property. 5 marks

Reveal model answer
Let T be an MST without lightest crossing edge e. T + e has a cycle crossing the cut twice, so it contains another crossing edge f with w(f) ≥ w(e). T − f + e is a spanning tree with weight ≤ w(T), hence an MST containing e.

Setup 1; cycle 2; exchange 2.
