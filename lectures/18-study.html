Chapter 02 / 07

Understand the greedy rule

Kruskal sorts edges by nondecreasing weight and accepts an edge if it connects two different current components. A disjoint-set union (DSU) tracks components. Initially each vertex is alone; union-by-size and path compression keep operations efficient. Stop after V−1 accepted edges for a connected graph.

Cut argument: assume a minimum spanning tree contains all accepted edges. Take the next accepted edge e crossing the cut of its current component; no cheaper crossing edge could have been skipped earlier while endpoints were disconnected now. If the tree lacks e, adding it creates a cycle with an edge f crossing the cut; f is not an already accepted edge. w(e)≤w(f), so exchanging f for e gives another minimum tree containing all choices. Induct to a spanning tree. Disconnected graphs return a minimum spanning forest, not a spanning tree.

Other proof methods: exchange (activity selection/SPT), stays-ahead (greedy finish no later at each selected count), lower bound (room allocation). Greedy rules require proof; optimal substructure alone is insufficient (Lecture 12).

def kruskal(n,edges):
    p=list(range(n));size=[1]*n
    def find(x):
        while p[x]!=x:
            p[x]=p[p[x]];x=p[x]
        return x
    total=0
    for w,u,v in sorted(edges):
        a,b=find(u),find(v)
        if a!=b:
            if size[a]<size[b]:a,b=b,a
            p[b]=a;size[a]+=size[b];total+=w
    return total
print(kruskal(4,[(1,0,1),(2,1,2),(3,0,2),(4,2,3),(5,1,3)]))

Time O(V+E log E+E α(V)) with union-by-size/path compression; α is inverse Ackermann, very slowly growing. O(V) DSU space plus graph/sorting storage. Negative edge weights are allowed for MST; not generally for Dijkstra. Detect disconnected input by counting accepted edges; use wide totals.
