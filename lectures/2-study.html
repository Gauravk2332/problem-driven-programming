Chapter 02 / 07

Understand the concept

Time complexity describes growth in an operation-count model, not seconds. Space complexity describes memory as input size changes. Auxiliary space is extra memory beyond input (and usually excluding required output, if stated). Total space includes input and output according to convention. A recursive call stack counts.

Best(n) = min work among inputs of size n
Worst(n) = max work among inputs of size n
Average(n) = expected work under a stated distribution

For successful linear search with target uniformly distributed among n distinct positions, E[C]=(1+2+…+n)/n=(n+1)/2. If probability of success is p, and successful positions are uniform, expected comparisons=p(n+1)/2+(1−p)n. Without a distribution there is no unique average case. Worst case includes unsuccessful search. Best comparison cost is 1 for nonempty input with first match. Best Θ(1), average Θ(n) under uniform successful search, worst Θ(n).

Chapter 03 / 07

Work through the reasoning

Count repetitions rather than lines. Two consecutive n-iteration loops give 2n, not n². Nested independent n loops give n². For i from 1 to n, an inner loop j from 1 to i runs n(n+1)/2 times. A loop repeatedly halving a positive integer until 0 runs floor(log₂ n)+1 times. Iterative binary search requires sorted data; each unsuccessful comparison discards roughly half.

For array size 8, a search for absent 10 in [1,3,5,7,9,11,13,15] probes middle indices 4,6,5 using half-open bounds: three visited indices (each probe may perform more than one primitive key comparison). Worst case can take four probes. Sorting solely for one lookup can cost more than scanning; repeated queries may justify preprocessing.

def linear(a,x):
    for i,v in enumerate(a):
        if v==x:return i,i+1
    return -1,len(a)
def binary(a,x):
    lo,hi=0,len(a);checks=0
    while lo<hi:
        mid=lo+(hi-lo)//2;checks+=1
        if a[mid]==x:return mid,checks
        if a[mid]<x:lo=mid+1
        else:hi=mid
    return -1,checks

Count one probe (visited index), not every primitive comparison. Both iterative methods use O(1) auxiliary space. Binary search worst O(log(n+1)) probes; empty input zero. Recursion uses additional stack frames. For very large arrays, use index types capable of representing the length and safe midpoint arithmetic.
