Design checklist

  1. Define the state precisely.
  2. Derive the transition from legal decisions.
  3. Set correct base cases and unreachable values.
  4. Choose a dependency order.
  5. Identify the output state.
  6. Count states × work; include stack and extra memory.

Three implementations

Memoization
Top-down recursion + cache; compute on demand.
Tabulation
Bottom-up; evaluate prerequisites first.
Rolling values
Retain only live dependencies; compute before shifting.

Minimum-energy jumps

h=[10,30,40,20,25,15], moves +1/+2, cost |h[i]−h[j]|. dp[i] = minimum energy from 0 to i.

dp[0]=0; dp[1]=|h[1]−h[0]|
dp[i]=min(dp[i−1]+|h[i]−h[i−1]|,
dp[i−2]+|h[i]−h[i−2]|)
i012345
dp02030303535

At i=3: min(30+20,20+10)=30. Answer 35; path 0→1→3→5. With parent history, backtrack and reverse.

Rolling update

if n=1: return 0
prev2=0; prev1=|h[1]−h[0]|
for i=2…n−1:
  curr=min(prev1+cost1,prev2+cost2)
  prev2=prev1; prev1=curr
return prev1

Only value retained. Input storage excluded.

Six states, 10 calls, 4 hits (memo caches base case; i−1 first).

Transfer: non-adjacent reward

R(k)=best for first k values. R(0)=0, R(1)=a[0]; R(k)=max(R(k−1),R(k−2)+a[k−1]) for nonnegative a. [2,7,9,3,1] gives 0,2,7,11,11,12. Optimum 12.

Common mistakes

  • State meaning changes mid-solution.
  • Zero used as uncomputed when zero is valid.
  • Out-of-bounds predecessor or wrong order.
  • Overwrite register before computing curr.
  • Forget recursion depth or reconstruction cost.

Full-marks answer

Define state, write base cases and recurrence, justify exhaustive last decisions, show order/table, extract answer, give time and auxiliary space.

5 marks: trace [8,3,10,6,7]: 0,5,2,6,5. 10 marks: derive, prove and compress the jump DP.

Top-down vs bottom-up

Top-down: memo keyed by stone i, recurse from dp[n−1]. Bottom-up: fill dp[0…n−1] by increasing i; roll to two values.
