Problem Driven Programming · R1UC544B
Lecture 21

Problem and state

Maximize Σvᵢxᵢ with Σwᵢxᵢ ≤ W, xᵢ ∈ {0,1}. Positive integer weights; nonnegative values. dp[i][c] = maximum value using first i items with weight at most c.

Recurrence

dp[0][c]=0; dp[i][0]=0
skip=dp[i−1][c]
if wᵢ>c: dp[i][c]=skip
else dp[i][c]=max(skip,vᵢ+dp[i−1][c−wᵢ])
Answer=dp[n][W]

Every feasible subset either takes i or skips it; previous row prevents repeat selection. Fill increasing rows; any column order for full 2D.

dp[4][7]=max(9,8+3)=11. Equal to previous row? Skip. Otherwise take and reduce capacity by weight. D, skip C, skip B, take A. A+D weighs 7, gives 11.

One-row compression

a[0..W]=0
for each (w,v):
  for c=W down to w:
   a[c]=max(a[c],v+a[c−w])
return a[W]

Descending preserves previous-row sources. Ascending with one item (2,3), W=6 gives wrong 9 instead of 3. Final row alone loses choice history.

Complexity

MethodTimeExtra space
RecursiveO(2ⁿ) boundO(n) stack
MemoO(nW)O(nW)+stack
2DO(nW)O(nW)
1DO(nW)O(W)

Shorthand for n,W≥1. W is numeric capacity; binary length is logarithmic. Pseudo-polynomial, not polynomial in bit length generally.

Greedy is not enough

W=50; (10,60),(20,100),(30,120). Ratio-first selects first two, value 160; last two give 220. Fractional version achieves 240, but pieces are not permitted here.

Common mistakes and exam guide

  • At most capacity differs from exact fill.
  • Read row i−1 in both cases.
  • Distinguish zero from uncomputed.
  • Use descending order for 0/1 compression.
  • Use 64-bit totals when necessary.

Full marks: state, bases, recurrence, proof by cases, order, table and answer, complexity. If requested, show backtracking or storage invariant.

Top-down vs bottom-up

Top-down: cache keyed by (i, c), recurse from solve(n, W); visits only needed pairs. Bottom-up: fill row by row; compress to one array, capacity descending.
