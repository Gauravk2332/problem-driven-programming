Chapter 04 / 13

Make smaller packing problems

Imagine a notebook whose rows say which items are available, and whose columns say how much weight is allowed. The question for dp[3][2] is: what is the maximum value if only the first three items are available and weight cannot exceed 2?

Columns are capacity limits, not required weights. You may leave room unused. The row counts items; it is not the index of the last item selected. With four items there are five rows including the empty prefix.

Chapter 05 / 13

Choose or skip the current item

Review the last available item. If you skip it, you keep the same capacity and one fewer possible item. If you take it, you gain its value, spend its weight and remove it from the remaining item list. This is why both branches refer to the previous row.

dp[0][c] = 0; dp[i][0] = 0 (positive weights)
if wᵢ > c: dp[i][c] = dp[i−1][c]
otherwise: dp[i][c] = max(dp[i−1][c], vᵢ + dp[i−1][c−wᵢ])
Answer = dp[n][W]

For D at capacity 7, skipping leaves value 9. Taking consumes 5 units and gains 8; the remaining capacity 2 can obtain 3 from earlier items. Compare 9 with 8+3, not just 9 with 8.

Chapter 06 / 13

Ask recursive questions and save answers

To answer solve(4,7), ask solve(3,7) and solve(3,2). Each call removes one item, even the take branch. If different branches reach the same (i,c), write the answer once and reuse it later. A valid zero result must not mean uncomputed; use −1, a separate visited flag or a dictionary.

Zero items means you can take nothing. Zero capacity means you can take no positive-weight item. The recursive stack still grows with item count, so use iteration for large n.

Chapter 08 / 13

Find which items were selected

The value alone doesn't tell you what to put in the bag. Start at the final cell. If the previous row with the same capacity achieves the same value, skip the current item. Otherwise take it and subtract its weight; move to the previous row. Repeat until no items remain.

For the default table: D increases 9 to 11, so take D and move to capacity 2. Skip C, skip B, take A. Reverse the selected list to get A,D. Equality permits one optimal skip choice, but other optimal selections may exist.

Chapter 09 / 13

Save memory without reusing an item

Think of the previous row as yesterday's notebook. To write today's row into the same notebook, do not erase the old answer before it is read. The take calculation reads a smaller capacity. Going right to left preserves that old answer; left to right may already have overwritten it with a solution that includes today's item.

Chapter 10 / 13

Translate the recurrence into programs

In recursion i decreases; in bottom-up computation i increases. In compressed storage, the outer loop still introduces one item at a time. Trace a small example before executing code.

knapsack.py

# items = (positive weight, nonnegative value); W >= 0
def memoized(items, W):
    n = len(items)
    memo = {}
    def solve(i, c):
        if i == 0 or c == 0:
            return 0
        if (i, c) in memo:
            return memo[i, c]
        w, v = items[i-1]
        ans = solve(i-1, c)
        if w <= c:
            ans = max(ans, v + solve(i-1, c-w))
        memo[i, c] = ans
        return ans
    return solve(n, W)

def tabulated(items, W):
    dp = [[0]*(W+1) for _ in range(len(items)+1)]
    for i, (w, v) in enumerate(items, 1):
        for c in range(W+1):
            dp[i][c] = dp[i-1][c]
            if w <= c:
                dp[i][c] = max(dp[i][c], v+dp[i-1][c-w])
    return dp[-1][W]

def compressed(items, W):
    dp = [0]*(W+1)
    for w, v in items:
        for c in range(W, w-1, -1):
            dp[c] = max(dp[c], v+dp[c-w])
    return dp[W]

if __name__ == "__main__":
    items = [(2,3),(3,4),(4,5),(5,8)]
    print(memoized(items,7), tabulated(items,7), compressed(items,7))

knapsack.cpp · C++17

#include <iostream>
#include <vector>
#include <utility>
#include <algorithm>
#include <functional>
using namespace std;
using ll = long long;
using Items = vector<pair<int,ll>>;
// Positive weights, nonnegative values, W >= 0.
ll memoized(const Items& a, int W) {
    vector<vector<ll>> memo(a.size()+1, vector<ll>(W+1,-1));
    function<ll(int,int)> solve = [&](int i,int c)->ll {
        if (i==0 || c==0) return 0;
        ll& r=memo[i][c];
        if (r!=-1) return r;
        auto [w,v]=a[i-1];
        r=solve(i-1,c);
        if (w<=c) r=max(r,v+solve(i-1,c-w));
        return r;
    };
    return solve(int(a.size()),W);
}
ll tabulated(const Items& a,int W) {
    vector<vector<ll>> dp(a.size()+1,vector<ll>(W+1));
    for (int i=1;i<=int(a.size());++i) {
        auto [w,v]=a[i-1];
        for (int c=0;c<=W;++c) {
            dp[i][c]=dp[i-1][c];
            if (w<=c) dp[i][c]=max(dp[i][c],v+dp[i-1][c-w]);
        }
    }
    return dp.back()[W];
}
ll compressed(const Items& a,int W) {
    vector<ll> dp(W+1);
    for (auto [w,v]:a)
        for (int c=W;c>=w;--c)
            dp[c]=max(dp[c],v+dp[c-w]);
    return dp[W];
}
int main() {
    Items a={{2,3},{3,4},{4,5},{5,8}};
    cout<<memoized(a,7)<<" "<<tabulated(a,7)<<" "<<compressed(a,7)<<"\n";
}

KnapsackDP.java

import java.util.Arrays;
public class KnapsackDP {
    // Each row is {positive weight, nonnegative value}.
    static long solve(int i,int c,int[][] a,long[][] memo) {
        if(i==0 || c==0) return 0;
        if(memo[i][c]!=-1) return memo[i][c];
        int w=a[i-1][0], v=a[i-1][1];
        long r=solve(i-1,c,a,memo);
        if(w<=c) r=Math.max(r,v+solve(i-1,c-w,a,memo));
        return memo[i][c]=r;
    }
    static long memoized(int[][] a,int W) {
        long[][] memo=new long[a.length+1][W+1];
        for(long[] row:memo) Arrays.fill(row,-1);
        return solve(a.length,W,a,memo);
    }
    static long tabulated(int[][] a,int W) {
        long[][] dp=new long[a.length+1][W+1];
        for(int i=1;i<=a.length;i++) {
            int w=a[i-1][0],v=a[i-1][1];
            for(int c=0;c<=W;c++) {
                dp[i][c]=dp[i-1][c];
                if(w<=c) dp[i][c]=Math.max(dp[i][c],v+dp[i-1][c-w]);
            }
        }
        return dp[a.length][W];
    }
    static long compressed(int[][] a,int W) {
        long[] dp=new long[W+1];
        for(int[] x:a)
            for(int c=W;c>=x[0];c--)
                dp[c]=Math.max(dp[c],x[1]+dp[c-x[0]]);
        return dp[W];
    }
    public static void main(String[] args) {
        int[][] a={{2,3},{3,4},{4,5},{5,8}};
        System.out.println(memoized(a,7)+" "+tabulated(a,7)+" "+compressed(a,7));
    }
}

Expected output: 11 11 11. Arrays are zero-indexed, while the state i counts how many items may be used. For these programs assume integer weights ≥1, nonnegative values, W≥0, weights and capacity within signed 32-bit range (with W+1 representable), and sum of values fits signed 64-bit (C++/Java). Use modest n,W for full tables and recursion; for large n use iteration, and for large nW use the 1D version if W is manageable. Python dictionary memoization stores only requested non-base states but recursion depth still grows with n. The website displays/copies code; run it locally or adapt the input to a judge.

Common mistakes

Does the bag have to be completely full?

No. At most W allows unused space. An exact-weight formulation initializes unreachable capacities to minus infinity.

Can two identical items both be used?

Yes, if they are two separate input items. A single item can only be used once.

What if capacity is zero?

All weights here are positive, so zero is the answer. Zero-weight items need a different treatment.

Can I backtrack from the final compressed row alone?

Not generally. You lost the previous rows needed to distinguish item choices.
