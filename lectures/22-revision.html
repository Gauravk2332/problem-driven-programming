Unbounded knapsack

K[i][c]=max value from first i types, unlimited copies, at most c. Positive weights; nonnegative values.

K[0][c]=0; K[i][0]=0
skip=K[i−1][c]
take=vᵢ+K[i][c−wᵢ] (if fits)
K[i][c]=max(skip,take)

Take stays in same row. Reconstruct by skipping on equality; otherwise reduce capacity, retain i. W=7; (2,3),(3,5),(5,7) → 11, two A + B.

Compression

for each (w,v):
  for c=w..W:
   d[c]=max(d[c],v+d[c−w])

Ascending uses updated same-row state. Descending is for 0/1.

Minimum coins

M[0]=0; M[a>0]=∞
M[a]=min(1+M[a−c]) for c≤a

Exact target; ignore unreachable sources, return −1 if impossible. {1,3,4}, 6 → 3+3 (2 coins), greedy 4+1+1 (3).

Unordered combinations

ways[0]=1; others 0
for coin c:
  for a=c..A:
   ways[a]+=ways[a−c]

State uses first i types; split by excluding/including a type. Same-row dependency permits repeat copies. Type outside prevents counting permutations.

Ordered sequences

ways[0]=1; others 0
for a=1..A:
  for coin c≤a:
   ways[a]+=ways[a−c]

Partition by last coin. For {1,2}, target 4: 3 multisets (1111,112,22); 5 sequences (1111,112,121,211,22).

Complexity and pitfalls

Unbounded O(nW) time; O(nW) full table or O(W) compressed. Coins O(mA) operations and O(A) space. Numeric capacities are pseudo-polynomial parameters. Positive inputs, distinct coin types. Target 0: minimum 0, count 1. Use wide integers or requested modulus for counts; never modulo optimum cost.

Full-marks answer

State meaning, legal repetitions, base cases, skip/take or last-coin proof, order, trace and answer, time and space. Explain exact target vs at-most limit and whether permutation changes the result.

Top-down vs bottom-up

Top-down: memo keyed by amount a for minimum coins. Unordered counting needs the key (coin type, amount); amount alone counts orders. Bottom-up: fill amounts 0…A.
