Subset Sum and Equal Sum Partition · Revision sheet

Problem Driven Programming · R1UC544B
Lecture 23

Problem and state

Given nonnegative integers, choose each occurrence at most once. Decide if exact sum T is reachable. D[i][s] means first i occurrences can make s.

D[0][0]=true; others false
D[i][s]=D[i−1][s] OR
 (xᵢ≤s AND D[i−1][s−xᵢ])
Answer D[n][T]

Skip/take cases cover every feasible subset; both use preceding row.

Worked example

[3,4,5,2], T=9. T/F table:

i/s0123456789
0TFFFFFFFFF
1TFFTFFFFFF
2TFFTTFFTFF
3TFFTTTFTTT
4TFTTTTTTTT

True. Skip 2, take 5, take 4, skip 3. Indices [1,2]. If final false, no witness. Otherwise compare previous same-sum cell; skip if true, else take and subtract; decrement i each step.

Space compression

d[0]=true; rest=false
for x in input:
  for s=T down to x:
   d[s]=d[s] OR d[s−x]

Descending preserves previous-row sources. [3], T=6: ascending incorrectly reaches 6. Zero causes OR with itself. Final row alone lacks full choice history.

Equal Sum Partition

S=sum(a)
if S odd: false
else subsetSum(a,S/2)

Subset half implies complement half. [1,5,11,5] → yes, [11] versus [1,5,5]. [1,2,5] → no despite even total. [1,2,4] → odd, no.

Complexity

Recursion O(2ⁿ) time, O(n) stack. Memo/table O(nT) time and O(nT) space, memo adds stack. Compressed O(nT) time, O(T) space (n,T≥1). Partition T=S/2. Numeric target means pseudo-polynomial. Backtracking O(n) after table.

Common confusions

  • Exact target differs from capacity limit.
  • Boolean OR is not addition or max.
  • False cache entry is a valid result.
  • Zero target is reachable by empty subset.
  • Duplicate values are distinct occurrences.
  • Negative numbers need a different sum domain.

Full-marks answer

State, bases, recurrence, proof by cases, dependency order, table, witness, complexity. For partition prove both directions and parity condition. Empty groups allowed in this formulation.
