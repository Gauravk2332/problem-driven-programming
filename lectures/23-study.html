Chapter 03 / 13

A notebook of possible sums

Imagine writing all reachable sums after each new box. Before any boxes, your list is {0}. After 3 it is {0,3}. After 4 it becomes {0,3,4,7}. Every old possibility remains by skipping the new box. Every shifted old possibility comes from taking it.

ReachableNew = ReachableOld ∪ {s+x : s∈ReachableOld, s+x≤T}

A Boolean table is just that membership list in grid form. D[i][s] answers whether sum s belongs to the reachable set after i occurrences.

Chapter 04 / 13

Why OR and why the preceding row?

Think of each target cell as a question with two doors. Door 1 skips today's box and asks whether the old list already contains s. Door 2 takes the box, then asks whether s−x is on the old list. If either door succeeds, the cell is true.

D[0][0]=true; D[0][s>0]=false
D[i][s]=D[i−1][s] OR (xᵢ≤s AND D[i−1][s−xᵢ])
Answer = D[n][T]

Look at sum 9 after 3,4,5: the old list with only 3,4 cannot make 9, but contains 4. Taking 5 plus 4 works. At target 0, take nothing: true.

Chapter 05 / 13

Remember recursive yes/no answers

Imagine asking your friend whether the first i boxes make s. They ask two smaller questions, with one fewer box. If two recursive branches ask identical (i,s), remember the answer, including false. A false answer is valid knowledge, not an empty cache.

The target zero succeeds immediately by taking nothing. With no boxes and a positive target the answer is false. Positive targets cannot be reached by taking a value greater than the remaining amount.

Which cache design distinguishes uncomputed from false?

Chapter 07 / 13

Find actual boxes, not just true

A true answer tells you some solution exists. Start at the last true cell. Try skipping the latest occurrence; if its previous-row cell is true, that is a valid path. Otherwise you must take it and move to the smaller sum. Always go up one row, even for zero.

Chapter 08 / 13

Save memory and avoid accidental reuse

We only need the previous row to decide the next. In a single array, update large sums before small ones. The small source has not yet learned today's item. Updating left to right might let today's box be used again.

d[0]=true; all other sums false
for each x in the array:
  for s=T down to x:
   d[s]=d[s] OR d[s−x]
return d[T]

Chapter 09 / 13

Split a whole array into equal sums

Imagine sharing all packages between two teams. Each package must go to one team; nothing can be left over. Add all weights first. If total is odd, no integer half exists. If total is even, the problem becomes: can team A receive a subset weighing exactly half? Team B automatically gets the other half.

Chapter 10 / 13

Translate the same recurrence to code

Compare the function signatures: the recursive method uses two arguments, the table makes rows explicitly, and the compressed method stores one row. The witness method needs the rows to decide which boxes to take. Partition computes the total then calls subset sum.

subset_dp.py

# Nonnegative integers; one use per input occurrence.
def memoized(a, T):
    from functools import lru_cache
    @lru_cache(None)
    def f(i, s):
        if s == 0: return True
        if i == 0: return False
        x = a[i-1]
        return f(i-1,s) or (x <= s and f(i-1,s-x))
    return f(len(a),T)

def table(a,T):
    d = [[False]*(T+1) for _ in range(len(a)+1)]
    d[0][0] = True
    for i,x in enumerate(a,1):
        for s in range(T+1):
            d[i][s] = d[i-1][s] or (x<=s and d[i-1][s-x])
    return d

def subset(a,T):
    d=[False]*(T+1); d[0]=True
    for x in a:
        for s in range(T,x-1,-1):
            d[s] = d[s] or d[s-x]
    return d[T]

def witness(a,T):
    d=table(a,T)
    if not d[-1][T]: return None
    result=[]; s=T
    for i in range(len(a),0,-1):
        if not d[i-1][s]:
            result.append(i-1); s-=a[i-1]
    return result[::-1] # indices, not values

def partition(a):
    S=sum(a)
    return S%2==0 and subset(a,S//2)

if __name__=="__main__":
    a=[3,4,5,2]
    print(memoized(a,9),table(a,9)[-1][9],subset(a,9))
    print(witness(a,9),partition([1,5,11,5]))

using Row=vector<char>;
using Grid=vector<Row>;
bool memoized(const vector<int>& a,int T){
    vector<vector<int>> m(a.size()+1,vector<int>(T+1,-1));
    function<bool(int,int)> f=[&](int i,int s)->bool{
        if(s==0)return true;
        if(i==0)return false;
        int& v=m[i][s];
        if(v!=-1)return v;
        int x=a[i-1];
        v=f(i-1,s)||(x<=s && f(i-1,s-x));
        return v;
    };
    return f(int(a.size()),T);
}
Grid table(const vector<int>& a,int T){
    Grid d(a.size()+1,Row(T+1)); d[0][0]=1;
    for(int i=1;i<=int(a.size());++i)
        for(int s=0;s<=T;++s){
            int x=a[i-1];
            d[i][s]=d[i-1][s]||(x<=s && d[i-1][s-x]);
        }
    return d;
}
bool subset(const vector<int>& a,int T){
    Row d(T+1); d[0]=1;
    for(int x:a) for(int s=T;s>=x;--s)
        d[s]=d[s]||d[s-x];
    return d[T];
}
bool witness(const vector<int>& a,int T,vector<int>& out){
    auto d=table(a,T); out.clear();
    if(!d.back()[T])return false;
    int s=T;
    for(int i=int(a.size());i>0;--i)
        if(!d[i-1][s]){out.push_back(i-1);s-=a[i-1];}
    reverse(out.begin(),out.end()); return true;
}
bool partition(const vector<int>& a){
    long long S=accumulate(a.begin(),a.end(),0LL);
    // assumes S/2 fits int and the allocation is feasible
    return S%2==0 && subset(a,int(S/2));
}

SubsetDP.java

import java.util.*;
public class SubsetDP {
    static boolean f(int[] a,int i,int s,int[][] m){
        if(s==0)return true;
        if(i==0)return false;
        if(m[i][s]!=-1)return m[i][s]==1;
        int x=a[i-1];
        boolean r=f(a,i-1,s,m)||(x<=s && f(a,i-1,s-x,m));
        m[i][s]=r?1:0; return r;
    }
    static boolean memoized(int[] a,int T){
        int[][] m=new int[a.length+1][T+1];
        for(int[] r:m)Arrays.fill(r,-1);
        return f(a,a.length,T,m);
    }
    static boolean[][] table(int[] a,int T){
        boolean[][] d=new boolean[a.length+1][T+1];
        d[0][0]=true;
        for(int i=1;i<=a.length;i++)
            for(int s=0;s<=T;s++){
                int x=a[i-1];
                d[i][s]=d[i-1][s]||(x<=s && d[i-1][s-x]);
            }
        return d;
    }
    static boolean subset(int[] a,int T){
        boolean[] d=new boolean[T+1];d[0]=true;
        for(int x:a)for(int s=T;s>=x;s--)d[s]|=d[s-x];
        return d[T];
    }
    static List<Integer> witness(int[] a,int T){
        boolean[][] d=table(a,T);
        if(!d[a.length][T])return null;
        List<Integer> out=new ArrayList<>();int s=T;
        for(int i=a.length;i>0;i--)
            if(!d[i-1][s]){out.add(i-1);s-=a[i-1];}
        Collections.reverse(out); return out;
    }
    static boolean partition(int[] a){
        long S=0;for(int x:a)S+=x;
        // assumes S/2 fits int and allocation is feasible
        return S%2==0 && subset(a,(int)(S/2));
    }
    public static void main(String[] args){
        int[] a={3,4,5,2};
        System.out.println(memoized(a,9)+" "+table(a,9)[a.length][9]+" "+subset(a,9));
        System.out.println(witness(a,9));
        System.out.println(partition(new int[]{1,5,11,5}));
    }
}

Expected: three true answers, witness indices [1,2] (4+5), equal partition true. C++ prints the indices separated by spaces. Inputs are nonnegative integers, target nonnegative, T+1 and partition half+1 fit int and allocation is feasible. C++/Java totals fit signed 64-bit; Python integers are exact. Recursion has depth O(n); for large n use iteration. The website displays and copies code; run it locally or adapt judge input.

Plain include/exclude recursion explores at most O(2ⁿ) branches, with O(n) stack. Dense memoization/table uses O((n+1)(T+1)) storage and time in the worst case, plus O(n) recursion stack for memo. Compressed DP uses O(T+1) auxiliary space and O((n+1)(T+1)) time; usually written O(nT), O(T) for n,T≥1. Backtracking scans n rows once and returns up to n indices. For equal partition use T=S/2. Because T is a numeric magnitude, not bit length, this is pseudo-polynomial. The general decision problem is NP-complete; a pseudo-polynomial algorithm does not establish P=NP.

Common confusion: two equal values

[3,3] contains two separate occurrences; choosing both gives 6. [3] contains only one, so cannot.

Why target zero is true

The empty subset is a valid witness. If a task requires a nonempty subset, explicitly adapt its base and zero handling.

Each array occurrence is distinct even when values match. Zero does not change Boolean reachability; it can double subset counts, so counting needs separate reasoning. With T=0 the empty subset is valid. We allow empty groups for equal partition (all-zero and empty inputs included); if a problem demands nonempty groups, handle zero-total cases explicitly. Negative values invalidate the simple 0..T truncation: use offset sums over a justified range or a set of reachable sums. A final compressed Boolean row does not by itself preserve reconstruction history.
