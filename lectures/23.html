Module 05 · Lecture 23

Subset Sum and Equal Sum Partition

Boolean DP · Exact reachability · Subset reconstruction · Equal partition

Section 01

The problem: can a target be reached?

Imagine four sealed boxes weighing 3,4,5,2 units. You need exactly 9 units, not the heaviest load below 9. Choose each box at most once. Is it possible?

Think first

Try choosing 5 first. Is a remainder of 4 available? What if the target is 1?

Reveal

Yes: 4+5=9 (also 3+4+2=9). Target 1 is impossible. Unlike profit maximization, the answer is a Boolean and a witness is optional.

All values and targets in this lecture are nonnegative integers. General subset sum can involve negative values, but the bounded table taught here assumes nonnegative input.

Section 02

State definition and proof by cases

Define D[i][s] = whether some subset of the first i occurrences sums exactly to s. With no items the only reachable sum is 0. Include or exclude the last occurrence; both branches use the previous row.

D[0][0]=true; D[0][s>0]=false
D[i][s]=D[i−1][s] OR (xᵢ≤s AND D[i−1][s−xᵢ])
Answer = D[n][T]

Correctness by induction: every feasible subset either contains xᵢ or does not. If it does not, the previous prefix achieves s. If it contains xᵢ, deleting that occurrence produces a previous-prefix subset of sum s−xᵢ. Conversely either true predecessor constructs a valid subset. OR implements existence. This is not a count or maximum.

Section 03

Recursion and memoization

Start from f(n,T). If target is zero return true; if no items remain return false. Otherwise try f(i−1,s) or, if x fits, f(i−1,s−x). Short-circuit OR can terminate early. Memoize the pair (i,s), and distinguish false from uncomputed.

f(i,s):
if s=0: return true
if i=0: return false
if cached: return saved answer
return/store f(i−1,s) OR (xᵢ≤s AND f(i−1,s−xᵢ))

Example: with repeated values [2,2,2], different choices can ask exactly the same prefix/remaining-sum question. Caching avoids re-expansion of identical states.

At D[3][9], skip gives D[2][9]=F; take 5 gives D[2][4]=T, so the cell is true. At D[4][9], skip is true and take 2 also leads to a true sum 7. Either choice gives a valid witness.

Section 05

Recover one subset

If the final answer is false, there is no witness. Otherwise start at (n,T). If D[i−1][s] is true, skip; otherwise take xᵢ and reduce s, then always decrement i. After i=0 the remaining sum is zero. Here skip 2, take 5, take 4, skip 3. Return indices [1,2] with values [4,5]. This deterministic skip-on-tie rule returns one witness, not all.

Section 06

Compress to a Boolean array

d[0]=true; all other sums false
for each x in the array:
  for s=T down to x:
   d[s]=d[s] OR d[s−x]
return d[T]

Invariant: before processing the current positive x, d is the previous row. Descending ensures d[s−x] is still from that row. If x=0 the update is d[s] OR itself, preserving reachability. Ascending may reuse a positive occurrence, making an impossible sum appear possible.

Why not simply use a set?

A set of reachable sums is also valid: update from a snapshot of the old set by unioning shifted sums. This can save work for sparse reachable sums but has different time/storage bounds; never iterate over freshly added sums as if they were old states.

Section 07

Reduce Equal Sum Partition to Subset Sum

Split all input indices into two disjoint groups with equal sums. Let total be S. If S is odd, impossible. For even S, choosing any subset with sum S/2 forces the complement to have the same sum.

S=Σa[i]
if S is odd: return false
otherwise return subsetSum(a,S/2)

Necessity and sufficiency follow from additivity of disjoint groups covering the entire input. Equal cardinality is not required. Even total is necessary but not sufficient.

Try [1,5,11,5], [1,2,5], [1,2,4] to compare feasible even, infeasible even, odd. For the first, [11] and [1,5,5] are equal.

Section 08

Implementation and complexity

subset_dp.py

# Nonnegative integers; one use per input occurrence.
def memoized(a, T):
    from functools import lru_cache
    @lru_cache(None)
    def f(i, s):
        if s == 0: return True
        if i == 0: return False
        x = a[i-1]
        return f(i-1,s) or (x <= s and f(i-1,s-x))
    return f(len(a),T)

def table(a,T):
    d = [[False]*(T+1) for _ in range(len(a)+1)]
    d[0][0] = True
    for i,x in enumerate(a,1):
        for s in range(T+1):
            d[i][s] = d[i-1][s] or (x<=s and d[i-1][s-x])
    return d

def subset(a,T):
    d=[False]*(T+1); d[0]=True
    for x in a:
        for s in range(T,x-1,-1):
            d[s] = d[s] or d[s-x]
    return d[T]

def witness(a,T):
    d=table(a,T)
    if not d[-1][T]: return None
    result=[]; s=T
    for i in range(len(a),0,-1):
        if not d[i-1][s]:
            result.append(i-1); s-=a[i-1]
    return result[::-1] # indices, not values

def partition(a):
    S=sum(a)
    return S%2==0 and subset(a,S//2)

if __name__=="__main__":
    a=[3,4,5,2]
    print(memoized(a,9),table(a,9)[-1][9],subset(a,9))
    print(witness(a,9),partition([1,5,11,5]))

using Row=vector<char>;
using Grid=vector<Row>;
bool memoized(const vector<int>& a,int T){
    vector<vector<int>> m(a.size()+1,vector<int>(T+1,-1));
    function<bool(int,int)> f=[&](int i,int s)->bool{
        if(s==0)return true;
        if(i==0)return false;
        int& v=m[i][s];
        if(v!=-1)return v;
        int x=a[i-1];
        v=f(i-1,s)||(x<=s && f(i-1,s-x));
        return v;
    };
    return f(int(a.size()),T);
}
Grid table(const vector<int>& a,int T){
    Grid d(a.size()+1,Row(T+1)); d[0][0]=1;
    for(int i=1;i<=int(a.size());++i)
        for(int s=0;s<=T;++s){
            int x=a[i-1];
            d[i][s]=d[i-1][s]||(x<=s && d[i-1][s-x]);
        }
    return d;
}
bool subset(const vector<int>& a,int T){
    Row d(T+1); d[0]=1;
    for(int x:a) for(int s=T;s>=x;--s)
        d[s]=d[s]||d[s-x];
    return d[T];
}
bool witness(const vector<int>& a,int T,vector<int>& out){
    auto d=table(a,T); out.clear();
    if(!d.back()[T])return false;
    int s=T;
    for(int i=int(a.size());i>0;--i)
        if(!d[i-1][s]){out.push_back(i-1);s-=a[i-1];}
    reverse(out.begin(),out.end()); return true;
}
bool partition(const vector<int>& a){
    long long S=accumulate(a.begin(),a.end(),0LL);
    // assumes S/2 fits int and the allocation is feasible
    return S%2==0 && subset(a,int(S/2));
}

    cout<<"\n"<<partition({1,5,11,5})<<"\n";

SubsetDP.java

import java.util.*;
public class SubsetDP {
    static boolean f(int[] a,int i,int s,int[][] m){
        if(s==0)return true;
        if(i==0)return false;
        if(m[i][s]!=-1)return m[i][s]==1;
        int x=a[i-1];
        boolean r=f(a,i-1,s,m)||(x<=s && f(a,i-1,s-x,m));
        m[i][s]=r?1:0; return r;
    }
    static boolean memoized(int[] a,int T){
        int[][] m=new int[a.length+1][T+1];
        for(int[] r:m)Arrays.fill(r,-1);
        return f(a,a.length,T,m);
    }
    static boolean[][] table(int[] a,int T){
        boolean[][] d=new boolean[a.length+1][T+1];
        d[0][0]=true;
        for(int i=1;i<=a.length;i++)
            for(int s=0;s<=T;s++){
                int x=a[i-1];
                d[i][s]=d[i-1][s]||(x<=s && d[i-1][s-x]);
            }
        return d;
    }
    static boolean subset(int[] a,int T){
        boolean[] d=new boolean[T+1];d[0]=true;
        for(int x:a)for(int s=T;s>=x;s--)d[s]|=d[s-x];
        return d[T];
    }
    static List<Integer> witness(int[] a,int T){
        boolean[][] d=table(a,T);
        if(!d[a.length][T])return null;
        List<Integer> out=new ArrayList<>();int s=T;
        for(int i=a.length;i>0;i--)
            if(!d[i-1][s]){out.add(i-1);s-=a[i-1];}
        Collections.reverse(out); return out;
    }
    static boolean partition(int[] a){
        long S=0;for(int x:a)S+=x;
        // assumes S/2 fits int and allocation is feasible
        return S%2==0 && subset(a,(int)(S/2));
    }
    public static void main(String[] args){
        int[] a={3,4,5,2};
        System.out.println(memoized(a,9)+" "+table(a,9)[a.length][9]+" "+subset(a,9));
        System.out.println(witness(a,9));
        System.out.println(partition(new int[]{1,5,11,5}));
    }
}

Expected: three true answers, witness indices [1,2] (4+5), equal partition true. C++ prints the indices separated by spaces. Inputs are nonnegative integers, target nonnegative, T+1 and partition half+1 fit int and allocation is feasible. C++/Java totals fit signed 64-bit; Python integers are exact. Recursion has depth O(n); for large n use iteration. The website displays and copies code; run it locally or adapt judge input.

Plain include/exclude recursion explores at most O(2ⁿ) branches, with O(n) stack. Dense memoization/table uses O((n+1)(T+1)) storage and time in the worst case, plus O(n) recursion stack for memo. Compressed DP uses O(T+1) auxiliary space and O((n+1)(T+1)) time; usually written O(nT), O(T) for n,T≥1. Backtracking scans n rows once and returns up to n indices. For equal partition use T=S/2. Because T is a numeric magnitude, not bit length, this is pseudo-polynomial. The general decision problem is NP-complete; a pseudo-polynomial algorithm does not establish P=NP.

Each array occurrence is distinct even when values match. Zero does not change Boolean reachability; it can double subset counts, so counting needs separate reasoning. With T=0 the empty subset is valid. We allow empty groups for equal partition (all-zero and empty inputs included); if a problem demands nonempty groups, handle zero-total cases explicitly. Negative values invalidate the simple 0..T truncation: use offset sums over a justified range or a set of reachable sums. A final compressed Boolean row does not by itself preserve reconstruction history.

Section 10

Summary and further reading

Exact feasibility differs from at-most optimization. Start with only zero reachable, combine previous-row cases using OR, descend for compressed one-use DP. For equal partition reduce an even total to half; reconstruct using previous rows when a witness is requested.
