Definition and state

Strictly increasing selected values and indices; gaps allowed. dp[i] = longest length ending exactly at i.

dp[i]=1+max(dp[j])
j<i and a[j]<a[i]
empty max=0; answer=max(dp)
empty array→0

Every sequence ending at i either stands alone or extends a legal previous endpoint.

Trace

Length 4. Follow 6→5→3→2, reverse to witness [2,5,7,101].

Binary search

tails[k]=minimum ending at length k+1. Smaller endings dominate larger ones. Records strictly increase.

for x in a:
 p=first tail ≥ x
 append if p=size
 else replace tails[p]
answer=size

For witness save parent[i]=ends[p−1] before replacement; follow final longest end. Tails alone is not a witness.

Counterexample

[3,5,6,2,4] gives final tails [2,4,6], invalid as an actual subsequence. Length 3; witness [3,5,6].

Costs and variants

Quadratic O(n²), O(n) extra. Fast O(n log n), O(n) with parents, O(L) length only. Strict < / lower_bound. Nondecreasing ≤ / upper_bound. Empty 0; nonempty all equal or decreasing 1.

Exam checklist

State, bases, recurrence, proof, order, trace, max, reconstruction and complexity. Do not sort the array or confuse contiguous runs with subsequences. Explain minimum-tail invariant.

Top-down vs bottom-up

Top-down: memo keyed by endpoint i, answer = max over all endpoints. Bottom-up: fill dp left to right. The O(n log n) tails method has no top-down form.
