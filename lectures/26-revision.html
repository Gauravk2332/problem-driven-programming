1. Partition / interval DP

Matrix i has dimensions p[i−1]×p[i]. M[i][j] = minimum scalar multiplication cost for contiguous chain i..j (1-based).

M[i][i]=0
M[i][j]=min over i≤k<j:
M[i][k]+M[k+1][j]
+ p[i−1]·p[k]·p[j]

Increasing interval length; O(n³) time, O(n²) space. Save best split. Example p=[10,30,5,60]: 4500 vs 27000; optimal (A1A2)A3.

2. Bitmask assignment

dp[mask] = minimum cost to assign first popcount(mask) workers to exactly the used jobs.

dp[0]=0; others=∞
i=popcount(mask)
for unused j:
next=mask OR (1<<j)
dp[next]=min(dp[next],
dp[mask]+cost[i][j])

Increasing mask order; answer all bits set. O(n·2ⁿ) time, O(2ⁿ) space. Save last job to reconstruct.

3. Digit DP

Count 0..N with digit sum S. State position, sum, tight (equal bound prefix). Pad leading zeros.

D[0][0][1]=1; others=0
limit=tight ? N[pos] : 9
choose x=0..limit, sum+x≤S
nt=tight AND (x=N[pos])
D[pos+1][sum+x][nt]+=D[pos][sum][tight]
answer: sum both tight states

Example N=25,S=4: 04,13,22 → 3. O(10L(S+1)) time, O(S+1) rolling space. F(R)−F(L−1), F(−1)=0.

Recognize and avoid errors

  • Interval: fixed order; split into contiguous parts. Don't reorder.
  • Mask: small n; subset identity matters. Never reuse a used bit.
  • Digit: huge range; use bound relation, not enumeration. Loose never becomes tight.
  • Digit properties involving length may need started flag; sum does not.
  • Check integer overflow and exponential memory.

Exam: state, base, transition, proof of sufficient state, dependency order, example and complexity.
