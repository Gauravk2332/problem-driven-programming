Chapter 02 / 13

Why parentheses matter

Think of three differently shaped grids. You must multiply them in their original order. The answer matrix is the same whichever legal parentheses you use, but the amount of work changes. An intermediate 10×5 grid is much smaller than multiplying the last two first, producing 30×60.

Chapter 03 / 13

Turn a chain into smaller chains

The final multiplication must join a left consecutive block and a right consecutive block. If you know the cheapest plan for each smaller block, only the last multiplication remains. Try splitting at every gap rather than assuming one locally cheap multiplication always works.

Aᵢ has dimensions pᵢ₋₁ × pᵢ (1-based matrices)
M[i][i]=0
M[i][j]=min over i≤k<j of (M[i][k]+M[k+1][j]+pᵢ₋₁·pₖ·pⱼ)
Fill by increasing interval length; answer M[1][n]

Matrix multiplication is associative, not commutative: preserve the order. Every full parenthesization has a unique last multiplication splitting a contiguous interval at k. Each half must use its own least-cost plan, since changing parentheses does not change the resulting dimensions. The last product costs p[i−1]·p[k]·p[j]. Compare all splits; both subintervals are shorter. Save the best split to recursively recover parentheses. The recurrence optimizes scalar multiplications under ordinary matrix multiplication cost, not every possible matrix multiplication algorithm.

Represent a set with bits

Chapter 06 / 13

Why identities matter

Imagine two workers have finished assigning jobs. Knowing only that two jobs are used is not enough: the last worker's options depend on which jobs remain. The used set is the important information. Histories with the same set can merge by keeping the cheaper cost.

Fix worker order. A mask stores which jobs have been used; popcount fixes the next worker. Different earlier assignments may yield the same mask, but the remaining available jobs and future costs are identical. Keeping the cheapest such partial assignment loses no better completion. Adding a missing bit strictly increases the integer mask, so increasing mask order is valid. Save the chosen last job on improvement; clear its bit to reconstruct in reverse worker order. This is exponential DP, not polynomial: assignment also has polynomial algorithms (e.g. Hungarian method); use the example to learn subset states.

Chapter 09 / 13

Count prefixes instead of numbers

Now attach a running sum to each prefix. Two prefixes with equal sum and equal bound relation have the same possible next steps. Add their counts instead of listing every number. Start with one empty prefix, sum zero, tight.

D[0][0][1]=1; all other states initially 0
State D[pos][sum][tight] counts valid prefixes
limit = tight ? N[pos] : 9
For 0≤x≤limit and sum+x≤S:
newTight = tight AND (x=N[pos])
D[pos+1][sum+x][newTight] += D[pos][sum][tight]
Answer D[L][S][0]+D[L][S][1]

Process digits from most significant to least significant. The bound is lexicographic among equal-length digit strings. If the prefix equals the bound (tight=1), the next digit cannot exceed the corresponding bound digit; if smaller (tight=0), any 0–9 is legal. Once loose, always loose. Every integer 0..N has exactly one padded representation, and each arises through exactly one digit-choice path. Accumulated sum and tight flag determine all future possibilities. Sum never decreases, so discard states above S. Leading zeros do not affect digit sum; properties involving length or first digit may need a separate started flag.

Top-down and bottom-up

All three patterns can be written top-down or bottom-up, and top-down is often the more natural first draft here.

Top-down (memoization)Bottom-up (tabulation)
Starts fromThe whole chain: cost(1, n)Single matrices: M[i][i] = 0
Stored byA memo keyed by the interval (i, j)A table M[i][j], filled by increasing interval length
How it runsRecursion. A state is solved the first time it is asked for, then read from the cacheLoops. Every state is filled once, after the states it depends on
Which statesOnly the states the final answer actually needsUsually every state in the table
Extra costA call stack as deep as the longest chain of calls; very deep inputs can overflow itNo recursion; the table can often be shrunk to one or two rows
Choose it whenThe fill order is awkward, or many states are never neededThe fill order is clear and most states are needed; this is the safer default for large inputs

For bitmask DP, top-down keys the memo by the mask; for digit DP, by (position, sum, tight). Bottom-up needs the order worked out first: increasing interval length, increasing mask, or digit by digit.

Python · chain_two_ways.py

def chain_top_down(p):
    # Top-down: cost(i, j) = cheapest way to multiply A_i ... A_j (1-based)
    n = len(p) - 1
    memo = {}

    def cost(i, j):
        if i == j:
            return 0
        if (i, j) not in memo:
            memo[(i, j)] = min(cost(i, k) + cost(k + 1, j) + p[i - 1] * p[k] * p[j]
                               for k in range(i, j))
        return memo[(i, j)]

    return cost(1, n)


def chain_bottom_up(p):
    # Bottom-up: solve all intervals of length 2, then 3, ... up to n
    n = len(p) - 1
    M = [[0] * (n + 1) for _ in range(n + 1)]
    for length in range(2, n + 1):
        for i in range(1, n - length + 2):
            j = i + length - 1
            M[i][j] = min(M[i][k] + M[k + 1][j] + p[i - 1] * p[k] * p[j] for k in range(i, j))
    return M[1][n]


print(chain_top_down([10, 30, 5, 60]), chain_bottom_up([10, 30, 5, 60]))              # 4500 4500
print(chain_top_down([40, 20, 30, 10, 30]), chain_bottom_up([40, 20, 30, 10, 30]))    # 26000 26000

long long cost(int i, int j) {
    if (i == j) return 0;
    if (memo[i][j] != -1) return memo[i][j];
    long long best = LLONG_MAX;
    for (int k = i; k < j; k++)

import java.util.Arrays;

public class ChainTwoWays {
    static long[] p;
    static long[][] memo;  // -1 means "not computed yet"

    // Top-down: cost(i, j) = cheapest way to multiply A_i ... A_j (1-based)
    static long cost(int i, int j) {
        if (i == j) return 0;
        if (memo[i][j] != -1) return memo[i][j];
        long best = Long.MAX_VALUE;
        for (int k = i; k < j; k++)
            best = Math.min(best, cost(i, k) + cost(k + 1, j) + p[i - 1] * p[k] * p[j]);
        return memo[i][j] = best;
    }

    static long chainTopDown() {
        int n = p.length - 1;
        memo = new long[n + 1][n + 1];
        for (long[] row : memo) Arrays.fill(row, -1);
        return cost(1, n);
    }

    // Bottom-up: solve all intervals of length 2, then 3, ... up to n
    static long chainBottomUp() {
        int n = p.length - 1;
        long[][] M = new long[n + 1][n + 1];
        for (int len = 2; len <= n; len++)
            for (int i = 1; i + len - 1 <= n; i++) {
                int j = i + len - 1;
                M[i][j] = Long.MAX_VALUE;
                for (int k = i; k < j; k++)
                    M[i][j] = Math.min(M[i][j], M[i][k] + M[k + 1][j] + p[i - 1] * p[k] * p[j]);
            }
        return M[1][n];
    }

    public static void main(String[] args) {
        p = new long[]{10, 30, 5, 60};
        System.out.println(chainTopDown() + " " + chainBottomUp());  // 4500 4500
        p = new long[]{40, 20, 30, 10, 30};
        System.out.println(chainTopDown() + " " + chainBottomUp());  // 26000 26000
    }
}

def matrix_chain(p):
    n=len(p)-1
    d=[[0]*n for _ in range(n)]
    for length in range(2,n+1):
        for i in range(n-length+1):
            j=i+length-1
            d[i][j]=min(d[i][k]+d[k+1][j]+p[i]*p[k+1]*p[j+1]
                        for k in range(i,j))
    return d[0][-1]

def assignment(c):
    n=len(c); d=[float('inf')]*(1<<n); d[0]=0
    for mask in range(1<<n):
        i=mask.bit_count()
        if i==n: continue
        for j in range(n):
            if not mask&(1<<j):
                nxt=mask|(1<<j)
                d[nxt]=min(d[nxt],d[mask]+c[i][j])
    return d[-1]

def digit_sum(N,S):
    d=[[0]*(S+1) for _ in range(2)]
    d[1][0]=1
    for lim in map(int,str(N)):
        nd=[[0]*(S+1) for _ in range(2)]
        for t in range(2):
            for s in range(S+1):
                for x in range(min(lim if t else 9,S-s)+1):
                    nd[int(t and x==lim)][s+x]+=d[t][s]
        d=nd
    return d[0][S]+d[1][S]

if __name__=='__main__':
    print(matrix_chain([10,30,5,60]))
    print(assignment([[9,2,7],[6,4,3],[5,8,1]]))
    print(digit_sum(25,4))
