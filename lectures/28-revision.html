Lecture 28

State and recurrence

C[0][0]=1 (open start)
C[i][j]=C[i−1][j]+C[i][j−1]
D[i][j]=g[i][j]+min(D[i−1][j],D[i][j−1])

Moves right/down only. Outside grid: count 0, cost ∞. Blocked cell: count 0, cost ∞ (zero is a real cost, never a sentinel).

Why it is correct

Each path arrives from above or left; the two groups are disjoint, so counts add. An optimal route has an optimal prefix. Both predecessors have smaller i+j, so row-major order is a valid order; induct on i+j.

Memory and complexity

cnt[j]+=cnt[j−1]   cost[j]=g+min(cost[j],cost[j−1])

Update left→right; reset blocked cells. Θ(RC) time; Θ(C) extra with a rolling row, Θ(RC) if the path must be reconstructed (≤ R+C−1 cells).

Common mistakes · full marks

  • Do not fill a whole edge with 1 when an edge cell is blocked.
  • Blocked start or destination ⇒ 0 paths.
  • Up/left moves break the order: use a graph algorithm.
  • Large counts: big integers or the required modulus.

Full marks: state, base, recurrence, order, complexity, trace.

Two-mark self-test

  1. Why is the start count one?
    The empty-move path starts and ends at the same open cell. A blocked start has none.
  2. What is the cost sentinel for unreachable cells?
    ∞; zero may be a legitimate path cost.
