Chapter 01 / 09

Recognize a path problem

Recall Lecture 20: a state records the cost to reach a position. Now a robot navigates a rectangular grid. It starts at the upper-left cell and may move right or down only. Each cell is either open with a nonnegative cost or blocked. Count routes and find the cheapest route, including both endpoint costs.

Think first

On an empty 3×3 grid, which moves lead to the destination? List three distinct routes.

Reveal the idea

Every route contains two right and two down moves, so there are 6 orders. Every arrival to a non-start cell has one of two last moves.

Chapter 02 / 09

Count without listing routes

Let C[i][j] count paths from (0,0) to (i,j). Every path arrives from above or left; these groups are disjoint because their last moves differ. Thus add their counts. The open start has one zero-move path. Outside the grid contributes zero.

C[0][0]=1
C[i][j]=C[i−1][j]+C[i][j−1] (non-start open cell)

Chapter 04 / 09

Change the objective, not the location

For minimum cost, D[i][j] stores the least sum of visited costs. Replace addition of counts by minimum of predecessor totals plus current cost. Infinity represents unreachable; zero is a valid cost and cannot mean unreachable. An optimal route has an optimal prefix because otherwise replacing it would improve the cost.

Count: C[0][0]=1 if open
C[i][j]=0 if blocked; otherwise C[i−1][j]+C[i][j−1]
Cost: D[0][0]=g[0][0] if open
D[i][j]=∞ if blocked; otherwise g[i][j]+min(D[i−1][j],D[i][j−1])
Outside grid: count 0, cost ∞. Treat start separately.

Chapter 05 / 09

Prove the order and compress memory

Both predecessors of (i,j) have a smaller row+column sum; row-major order is one valid topological order. Induction proves the count and cost formulas since the two predecessor solutions are already correct. For a rolling array, before updating column j, dp[j] is above and dp[j−1] is current-row left. Update left to right, never right to left for this recurrence.

count[j] = count[j] + (j>0 ? count[j−1] : 0)
cost[j] = g[i][j] + min(old cost[j], current cost[j−1])

Reset blocked cells to 0/∞. Full tables O(RC) time and O(RC) memory; rolling O(RC) time and O(C) extra memory. Transpose to use smaller dimension if movements and costs transform consistently. To reconstruct a minimum path, store predecessor choices in a full table and walk backward to start; reverse. At most R+C−1 visited cells. If up/left movements are allowed, this dependency order no longer solves the general problem; use a suitable graph algorithm.

def solve(g):
    if not g or not g[0]: return 0, -1
    c=[0]*len(g[0]); d=[float('inf')]*len(c)
    for i,row in enumerate(g):
        for j,w in enumerate(row):
            if w is None: c[j]=0; d[j]=float('inf')
            elif i==j==0: c[j]=1; d[j]=w
            else:
                c[j]+=c[j-1] if j else 0
                d[j]=w+min(d[j],d[j-1] if j else float('inf'))
    return c[-1], d[-1] if c[-1] else -1

Rectangular grid, nonnegative costs, blocked marker None (Python) or −1 (C++/Java). Fixed-width versions require every intermediate count to fit signed 64-bit and every finite path cost to be below 2⁶⁰. For large path-count problems use exact big integers or the required modulus; do not use a modular count of zero to infer unreachability. Cost and count both use O(columns) auxiliary memory; reconstruction requires history.

For unobstructed grids only, C[R−1][C−1]=binom(R+C−2,R−1). This counts move orders; obstacles invalidate the simple formula.
