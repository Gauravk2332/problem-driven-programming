State and recurrence

L[i][0]=L[0][j]=0
A[i−1]=B[j−1]: L[i][j]=1+L[i−1][j−1]
else: L[i][j]=max(L[i−1][j],L[i][j−1])

L[i][j] = best length for the first i symbols of A and first j of B. Answer L[m][n]. Subsequence: may skip, may not reorder.

Why it is correct

Equal final symbols: some optimum matches them together, giving diagonal+1. Different: no common subsequence uses both final positions, so drop one and take the max. Induction on i+j.

Worked example

A=ABCBDAB, B=BDCABA: L=4. Backtracking (ties go up) gives BCBA; BDAB is another optimum. A length is not a witness.

Complexity · mistakes

Θ(mn) time; Θ(mn) space for a witness, two rows (Θ(min(m,n))) for length only. Backtrack Θ(m+n).

  • Prefix length i means last symbol A[i−1].
  • Replacement allowed ⇒ edit distance (Lecture 25), not the LCS formula.

Two-mark self-test

  1. Define subsequence versus substring.
    Subsequence preserves order but allows gaps; substring is contiguous.
  2. Why are both base borders zero?
    One input prefix is empty, so no nonempty common subsequence exists.
