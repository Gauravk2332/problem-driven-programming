Chapter 02 / 10

Define two prefixes

L[i][j] is the maximum common subsequence length for A's first i symbols and B's first j symbols. Prefix length is not a character index: the last symbols are A[i−1], B[j−1]. An empty prefix cannot match anything, so both borders are zero.

L[i][0]=L[0][j]=0
if A[i−1]=B[j−1]: L[i][j]=1+L[i−1][j−1]
else: L[i][j]=max(L[i−1][j],L[i][j−1])
Answer L[m][n]

Chapter 03 / 10

Why matching and skipping work

If final symbols match, there is an optimum that matches them together. Take any optimum: if it already uses a final symbol, its last matched symbol has that value and can be moved to the final position in both strings; if it uses neither final symbol, appending the shared symbol would improve it. Hence the optimum equals 1+L[i−1][j−1]. If symbols differ, no common subsequence can use both final positions (they would have to be matched together at its end). At least one is omitted; choose max of the two shorter-prefix optima. Induction on i+j gives correctness. Compare Edit Distance (Lecture 25), which minimizes cost rather than maximizing kept symbols.

Chapter 05 / 10

Recover an actual subsequence

Start at (m,n). When characters match, record the character and move diagonally. Otherwise move to the neighbor with greater DP value, choosing above on ties. Stop when either prefix is empty, reverse recorded symbols. Every nonmatch move preserves the optimal remaining length; every match consumes exactly one unit. This yields one valid LCS. It does not enumerate all optimal strings or guarantee lexicographically smallest LCS.

Position (i,j)Action
(7,6)Skip A symbol
(6,6)Record A
(5,5)Skip A symbol
(4,5)Record B
(3,4)Skip B symbol
(3,3)Record C
(2,2)Skip B symbol
(2,1)Record B
(1,0)Stop

Reverse to get BCBA. If only length is required, keep previous and current rows; diagonal and above are from previous, left from current. O(mn) time for positive lengths; O(min(m,n)+1) auxiliary storage when columns are shorter. Full table O((m+1)(n+1)); witness backtracking O(m+n) steps.

Translate the recurrence into code

def lcs(a,b):
    d=[[0]*(len(b)+1) for _ in range(len(a)+1)]
    for i,x in enumerate(a,1):
        for j,y in enumerate(b,1):
            d[i][j]=1+d[i-1][j-1] if x==y else max(d[i-1][j],d[i][j-1])
    i,j=len(a),len(b);out=[]
    while i and j:
        if a[i-1]==b[j-1]:out.append(a[i-1]);i-=1;j-=1
        elif d[i-1][j]>=d[i][j-1]:i-=1
        else:j-=1
    return ''.join(reversed(out))
s=lcs("ABCBDAB","BDCABA")
print(len(s),s)

ASCII examples ensure all three languages use the same character units. For length-only computation keep two rows and use the shorter string as columns. Full table reconstruction O(m+n) steps; full DP O((m+1)(n+1)) time and space. Very large strings require checking available memory and index ranges.

Do not allocate a full table if the task only needs length and memory is limited. For Unicode grapheme clusters, tokenize consistently before comparing; these examples use ASCII.
