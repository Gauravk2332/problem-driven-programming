Definitions (for all n ≥ n₀)

ConditionMeaning
O(g)f ≤ c·gupper bound
Ω(g)f ≥ c·glower bound
Θ(g)c₁g ≤ f ≤ c₂gtight bound

Prove with a witness (c, n₀); disprove by showing none exists.

Worked witness

3n² + 5n + 2: ≥ 3n² (n ≥ 1); ≤ 4n² for n ≥ 6 (5n + 2 ≤ n²; fails at 5: 102 > 100) ⇒ Θ(n²), c₁ = 3, c₂ = 4, n₀ = 6. Also ≤ 10n² for n ≥ 1.

Growth order

1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n! < nⁿ

100n vs n²: equal at 100, n² larger from 101. 2ⁿ > n³ from n = 10.

Rules

  • constants drop: c·f = Θ(f)
  • sum: f + g = Θ(max)
  • product: O(f)·O(g) = O(fg)
  • degree-k polynomial = Θ(nᵏ)
  • log bases differ by a constant

Common mistakes · full marks

  • Big-O ≠ worst case: bounds and cases are independent.
  • O is not symmetric: n = O(n²), n² ≠ O(n).
  • Numeric checks are evidence, not proof.

Full marks: definition with quantifiers, explicit c and n₀, algebra, correct conclusion.

Two-mark self-test

  1. Define Big-O notation.
    f(n) = O(g(n)) if there exist constants c > 0 and n₀ ≥ 1 such that 0 ≤ f(n) ≤ c·g(n) for all n ≥ n₀.
  2. Define Θ notation.
    f = Θ(g) if there exist c₁, c₂ > 0 and n₀ with c₁g(n) ≤ f(n) ≤ c₂g(n) for all n ≥ n₀.
  3. Show 2n + 3 = O(n).
    2n + 3 ≤ 3n for n ≥ 3, so c = 3, n₀ = 3 (or 2n + 3 ≤ 5n for n ≥ 1).
  4. Arrange: n log n, 2ⁿ, log n, n².
    log n < n log n < n² < 2ⁿ.
  5. Is n² = O(n)? Justify.
    No. n² ≤ cn would require n ≤ c for all large n, impossible.
