Chapter 02 / 07

Understand the concept

For eventually nonnegative functions f,g, with g positive for sufficiently large n:

f∈O(g) iff ∃ c>0,n₀: 0≤f(n)≤c·g(n) for n≥n₀
f∈Ω(g) iff ∃ c>0,n₀: 0≤c·g(n)≤f(n) for n≥n₀
f∈Θ(g) iff ∃ c₁,c₂>0,n₀: 0≤c₁g(n)≤f(n)≤c₂g(n) for n≥n₀

O is an eventual upper bound, Ω a lower bound, Θ a tight bound. These are not synonyms for worst, best and average cases. You may analyse the worst-case function with Θ or Ω, and the best-case function with O. A function may have many valid loose bounds; use the tight one when known.

Chapter 03 / 07

Work through the reasoning

Prove f(n)=3n²+5n+2 is Θ(n²). For n≥1, n≤n² and 1≤n², hence f≤10n². Also f≥3n². Choose c₁=3,c₂=10,n₀=1. Thus f is both O(n²) and Ω(n²). It is also O(n³), but not Θ(n³) since f/n³→0.

Growth classTypical example
Θ(1)Fixed number of operations
Θ(log n)Repeated halving
Θ(n)Scan
Θ(n log n)Merge sort
Θ(n²)All ordered pairs
Θ(n³)Three nested n loops
Θ(2ⁿ)All subsets (one unit per subset)
Θ(n!)All permutations (one unit per permutation)

Asymptotic order for large n≥2 is 1, log n, n, n log n, n², n³, 2ⁿ, n!. Log bases differ by a constant. Polynomial sums are dominated by their highest nonzero positive-power term. Multiplying by a constant does not change Θ. For independent sizes n,m, preserve both unless a relation is given. Outputting each subset explicitly can cost O(n2ⁿ), not merely Θ(2ⁿ).

def triangular(n):
    count=0
    for i in range(1,n+1):
        for j in range(i):count+=1
    return count
for n in [4,8,16]:
    print(n,triangular(n))

Exam revision

O(g) upper, Ω(g) lower, Θ(g) both. Include constants and threshold in a proof. Do not equate notations with input cases. For n≥1, n²/2≤n(n+1)/2≤n². Dominant growth: constant, logarithmic, linear, n log n, quadratic, cubic, exponential, factorial. Use tight bounds when justified.
