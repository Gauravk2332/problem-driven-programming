Chapter 02 / 10

Build a two-state machine

After i houses, skip[i] is the best total when house i−1 was skipped; take[i] when it was chosen. At i=0, skip=0, take=−∞ because no house was taken. From skip, skip again or take; from take, only skip. Never initialize impossible take to a real reward.

skip[i+1]=max(skip[i],take[i])
take[i+1]=skip[i]+v[i]
Answer max(skip[n],take[n])

Chapter 04 / 10

Model whether a share is held

Now prices are [7,1,5,3,6,4]. At most one share may be held; buy or sell at today's price, at most one action per day, unlimited completed trades, no fees, no cooldown, no short selling. Finish without owning a share. Cash[i] is maximum net profit after i days while holding none; hold[i] is maximum net profit after i days while holding one (purchase cost already subtracted). Hold can be negative; it is not the market value.

cash[i+1]=max(cash[i],hold[i]+p[i])
hold[i+1]=max(hold[i],cash[i]−p[i])
Base cash=0, hold=−∞; answer cash[n]

Every next state is reached by exactly one of its legal incoming actions: stay or trade. The best past profit with the same state dominates lesser histories since future legal actions and rewards depend only on that state and the day. This gives an induction proof for both problems.

Chapter 06 / 10

Extend the state when the rules change

Fee f on sale: cash'=max(cash,hold+p−f), hold'=max(hold,cash−p). Cooldown after selling: add a third state. At end of day, rest means no share and not just sold; sold means sold today; hold means owns a share. Transitions from yesterday:

rest'=max(rest,sold)
sold'=hold+p
hold'=max(hold,rest−p)
Base (rest,sold,hold)=(0,−∞,−∞)
Answer max(rest,sold)

Buying requires yesterday's rest, so a sale today blocks buying tomorrow. For limited transactions add a completed-sale counter; do not reuse unlimited recurrence without adjusting it. These are optional extensions. The core principle: add only the memory that changes future choices.

Chapter 07 / 10

Implement safe rolling transitions

def robber(a):
    skip,take=0,float('-inf')
    for v in a: skip,take=max(skip,take),skip+v
    return max(skip,take)
def stock(a):
    cash,hold=0,float('-inf')
    for p in a: cash,hold=max(cash,hold+p),max(hold,cash-p)
    return cash
print(robber([2,7,9,3,1]))
print(stock([7,1,5,3,6,4]))
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
using ll=long long;
const ll NEG=-(1LL<<60);
ll robber(const vector<int>& a){
 ll skip=0,take=NEG;
 for(ll v:a){ll ns=max(skip,take),nt=skip+v;skip=ns;take=nt;}
 return max(skip,take);
}
ll stock(const vector<int>& a){
 ll cash=0,hold=NEG;
 for(ll p:a){ll nc=max(cash,hold==NEG?NEG:hold+p),nh=max(hold,cash-p);cash=nc;hold=nh;}
 return cash;
}
int main(){cout<<robber({2,7,9,3,1})<<"\n"<<stock({7,1,5,3,6,4})<<"\n";}
class Main{
 static final long NEG=-(1L<<60);
 static long robber(int[] a){
  long skip=0,take=NEG;
  for(int v:a){long ns=Math.max(skip,take),nt=skip+v;skip=ns;take=nt;}
  return Math.max(skip,take);
 }
 static long stock(int[] a){
  long cash=0,hold=NEG;
  for(int p:a){long nc=Math.max(cash,hold==NEG?NEG:hold+p),nh=Math.max(hold,cash-p);cash=nc;hold=nh;}
  return cash;
 }
 public static void main(String[] args){
  System.out.println(robber(new int[]{2,7,9,3,1}));
  System.out.println(stock(new int[]{7,1,5,3,6,4}));
 }
}

Expected output: 12; then 7. Copy and run locally; this site does not execute code.

Nonnegative integer rewards/prices, empty input allowed. For fixed-width examples require total possible gains below 2⁶⁰; NEG denotes an impossible state and is guarded before addition. O(n) time, O(1) auxiliary space for value only. To return an explicit schedule store predecessor decisions; use previous states, not partly updated values.

Both next values must read the previous pair. In-place updates can enable an illegal extra action in variants. Use temporary variables or Python simultaneous assignment. Store a predecessor table if asked to recover chosen houses or trades.

Chapter 10 / 10

Revision and exam-style questions

State machines express legal next actions. Initialize impossible states to −∞ and update from old values. Non-adjacent selection uses skip/take; trading uses cash/hold, with terminal cash. Time O(n), value-only auxiliary O(1). Add fee in sale transition or cooldown eligibility state when rules change.

Robbery: skip'=max(skip,take); take'=skip+v
Stock: cash'=max(cash,hold+p); hold'=max(hold,cash−p)
Initialize (0,−∞); compute both next states from old states.
Answer: max(skip,take) for robbery; cash for stock.

Answer: max(skip,take) for robbery; cash for stock.

Each state merges histories with identical future legal actions. For cooldown use rest,sold,hold; rest'=max(rest,sold), sold'=hold+p, hold'=max(hold,rest−p). Start rest=0, others −∞; return max(rest,sold). O(n) time and O(1) rolling space.
