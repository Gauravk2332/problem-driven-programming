Writing a recurrence

T(n) = (number of calls) × T(size) + work outside calls; plus a base case.

AlgorithmRecurrenceΘ
test(n−1)T(n−1) + 1n
binary searchT(n/2) + 1log n
merge sort2T(n/2) + nn log n
Hanoi2T(n−1) + 12ⁿ

Back substitution

T(n−1)+n = n(n+1)/2 (T(10) = 55). 2T(n−1)+1 = 2ⁿ − 1 (T(10) = 1023). T(n/2)+1 = log₂ n + 1.

Recursion tree

2T(n/2)+n, n = 16: levels cost 16, 16, 16, 16 + 16 leaves = 80 = n log₂ n + n.

Master Theorem: T = aT(n/b) + Θ(n^d)

CompareT(n)
d < log_b aΘ(n^(log_b a)) — leaves
d = log_b aΘ(n^d log n) — even
d > log_b aΘ(n^d) — root

8T(n/2)+n² → n³; 2T(n/2)+n² → n²; 3T(n/4)+n → n; 7T(n/2)+n² → n^2.81.

Does not apply

Decreasing (T(n−1)…), non-constant a, unequal splits, f = n/log n (basic form). Decreasing: a = 1 ⇒ ≈ n·f(n); a > 1 ⇒ exponential.

Common mistakes · full marks

  • 2T(n−1) is exponential; 2T(n/2) is not.
  • Count levels: log_b n.
  • Expansion finds a pattern; induction proves it.

Full marks: recurrence with base case, method named, working shown, Θ result.

Two-mark self-test

  1. What is a recurrence relation?
    An equation that defines a function in terms of its values on smaller inputs, with one or more base cases; e.g. T(n) = 2T(n/2) + n, T(1) = 1.
  2. Solve T(n) = T(n − 1) + 1, T(0) = 0.
    Back substitution: T(n) = T(0) + n = n = Θ(n).
  3. State the Master Theorem (simplified form).
    For T(n) = aT(n/b) + Θ(n^d): Θ(n^d) if d > log_b a; Θ(n^d log n) if d = log_b a; Θ(n^(log_b a)) if d < log_b a.
  4. Solve T(n) = 2T(n/2) + n by the Master Theorem.
    a = 2, b = 2, d = 1, log₂2 = 1 = d: case 2, Θ(n log n).
  5. Give a recurrence the Master Theorem cannot solve.
    T(n) = T(n − 1) + n (decreasing), or T(n) = 2T(n/2) + n/log n.
