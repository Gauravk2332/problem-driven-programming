Chapter 01 / 13

Start with a problem

Here is a recursive function. How many times does it print?

void test(int n):
  if n > 0:
    print(n)
    test(n − 1)
Think first

Count the prints for n = 3, then write the cost of test(n) using the cost of test(n − 1).

A cost that refers to itself
test(3) prints 3, 2, 1: three prints. In general T(n) = T(n − 1) + 1 with T(0) = 0, so T(n) = n.

Loops can be counted directly, but a recursive algorithm’s cost is naturally described by a recurrence relation: an equation that defines T(n) in terms of T on smaller inputs, plus a base case. This lecture is about writing and solving them.

From code to a recurrence

Chapter 03 / 13

Method 1: back substitution

Expand the recurrence repeatedly until a pattern appears, then use the base case.

T(n) = T(n − 1) + n, T(1) = 1

T(n) = T(n − 1) + n = T(n − 2) + (n − 1) + n = … = T(1) + 2 + 3 + … + n = n(n + 1)/2 = Θ(n²). Check: T(10) = 55.

T(n) = 2T(n − 1) + 1, T(1) = 1 (Tower of Hanoi)

T(n) = 2T(n − 1) + 1 = 4T(n − 2) + 2 + 1 = … = 2ᵏT(n − k) + (2ᵏ − 1). Put k = n − 1: T(n) = 2ⁿ⁻¹ + 2ⁿ⁻¹ − 1 = 2ⁿ − 1. Check: T(10) = 1023.

T(n) = T(n/2) + 1, T(1) = 1 (binary search), n = 2ᵏ

T(n) = T(n/4) + 2 = … = T(n/2ᵏ) + k = T(1) + log₂ n = log₂ n + 1 = Θ(log n).

Chapter 04 / 13

Explore: the recursion tree

A recursion tree draws each call as a node labelled with its own work. Adding the levels gives T(n). Set a, b and d for T(n) = a·T(n/b) + n^d with T(1) = 1.

Think first

Try (2, 2, 1), then (8, 2, 2), then (1, 2, 0). Where is most of the work: at the top, spread evenly, or at the leaves?

Three shapes
(2, 2, 1): every level costs n, so T = n·(levels) = Θ(n log n). (8, 2, 2): level costs double each level down, so the leaves dominate: Θ(n³). (1, 2, 0): one node per level costing 1: Θ(log n).

Chapter 06 / 13

Method 3: the Master Theorem

For T(n) = a·T(n/b) + Θ(n^d) with constants a ≥ 1, b > 1, d ≥ 0, compare d with log_b a (the exponent of the number of leaves, n^(log_b a)):

CaseConditionT(n)Where the work is
1d < log_b aΘ(n^(log_b a))leaves
2d = log_b aΘ(n^d log n)evenly across levels
3d > log_b aΘ(n^d)root
Recurrencea, b, dlog_b aResult
2T(n/2) + n (merge sort)2, 2, 11Θ(n log n)
T(n/2) + 1 (binary search)1, 2, 00Θ(log n)
8T(n/2) + n²8, 2, 23Θ(n³)

7T(n/2) + n² (Strassen)7, 2, 2≈ 2.81Θ(n^2.81)

The general form (optional)

CLRS states the theorem for any f(n): case 1 if f = O(n^(log_b a − ε)), case 2 if f = Θ(n^(log_b a)), case 3 if f = Ω(n^(log_b a + ε)) and a·f(n/b) ≤ k·f(n) for some k < 1 (the regularity condition). The extended case 2 gives T = Θ(n^(log_b a) log^(k+1) n) when f = Θ(n^(log_b a) logᵏ n).

For decreasing recurrences T(n) = a·T(n − b) + f(n): with a = 1 the answer is about n·f(n) (Θ(n) for constant f, Θ(n²) for f = n); with a > 1 it is exponential, Θ(a^(n/b)·f(n)).

Chapter 08 / 13

Method 4: guess and prove (substitution method)

Guess the form of the answer, then prove it by induction. This is how bounds are proved rigorously.

Claim: T(n) = 2T(n/2) + n with T(1) = 1 satisfies T(n) ≤ n log₂ n + n for n a power of 2

  1. Base: T(1) = 1 ≤ 1·0 + 1.
  2. Step: assume T(n/2) ≤ (n/2) log₂(n/2) + n/2. Then T(n) ≤ 2[(n/2)(log₂ n − 1) + n/2] + n = n log₂ n − n + n + n = n log₂ n + n.

Hence T(n) = O(n log n). (Here the bound is in fact exact.)

A wrong guess shows up as an induction step that does not close: guessing T(n) ≤ cn for this recurrence leads to T(n) ≤ cn + n, which is not ≤ cn for any constant c.

Why does the guess T(n) ≤ cn fail for T(n) = 2T(n/2) + n?

Checking solutions with code

The program evaluates three recurrences directly and compares them with their closed forms, then classifies six dividing recurrences with the Master Theorem.

Python · recurrence.py

"""Lecture 4: evaluating recurrences and the Master Theorem."""
import math
from functools import lru_cache


@lru_cache(maxsize=None)
def merge_t(n):            # T(n) = 2T(n/2) + n, T(1) = 1, n a power of 2
    return 1 if n == 1 else 2 * merge_t(n // 2) + n


@lru_cache(maxsize=None)
def linear_t(n):           # T(n) = T(n-1) + n, T(1) = 1
    return 1 if n == 1 else linear_t(n - 1) + n


@lru_cache(maxsize=None)
def hanoi_t(n):            # T(n) = 2T(n-1) + 1, T(1) = 1
    return 1 if n == 1 else 2 * hanoi_t(n - 1) + 1


def master(a, b, d):
    """T(n) = a T(n/b) + Theta(n^d)."""
    e = math.log(a, b)
    if abs(e - d) < 1e-9:
        return "Theta(log n)" if d == 0 else ("Theta(n log n)" if d == 1 else f"Theta(n^{d} log n)")
    if d > e:
        return f"Theta(n^{d})" if d != 1 else "Theta(n)"
    return f"Theta(n^{e:.2f})" if abs(e - round(e)) > 1e-9 else f"Theta(n^{round(e)})"


for k in range(0, 6):
    n = 2 ** k
    print(f"n={n:>2}: 2T(n/2)+n = {merge_t(n):>3}   n*log2(n)+n = {n * k + n:>3}")
print("T(n)=T(n-1)+n, n=10:", linear_t(10), "= n(n+1)/2 =", 10 * 11 // 2)
print("T(n)=2T(n-1)+1, n=10:", hanoi_t(10), "= 2^n - 1 =", 2 ** 10 - 1)
for a, b, d in [(2, 2, 1), (1, 2, 0), (8, 2, 2), (2, 2, 2), (7, 2, 2), (3, 4, 1)]:
    print(f"a={a} b={b} d={d}: log_b a = {math.log(a, b):.2f} -> {master(a, b, d)}")

C++ · recurrence.cpp

// Lecture 4: evaluating recurrences and the Master Theorem.
#include <cmath>
#include <cstdio>
#include <string>
using namespace std;

long long mergeT(long long n) { return n == 1 ? 1 : 2 * mergeT(n / 2) + n; }   // T(n) = 2T(n/2) + n
long long linearT(long long n) { return n == 1 ? 1 : linearT(n - 1) + n; }     // T(n) = T(n-1) + n
long long hanoiT(long long n) { return n == 1 ? 1 : 2 * hanoiT(n - 1) + 1; }   // T(n) = 2T(n-1) + 1

string master(int a, int b, int d) {      // T(n) = a T(n/b) + Theta(n^d)
    double e = log((double)a) / log((double)b);
    char buf[64];
    if (fabs(e - d) < 1e-9) return d == 0 ? "Theta(log n)" : d == 1 ? "Theta(n log n)" : "Theta(n^" + to_string(d) + " log n)";
    if (d > e) return d != 1 ? "Theta(n^" + to_string(d) + ")" : "Theta(n)";
    if (fabs(e - round(e)) > 1e-9) { snprintf(buf, sizeof buf, "Theta(n^%.2f)", e); return buf; }
    return "Theta(n^" + to_string((int)round(e)) + ")";
}

int main() {
    for (int k = 0; k < 6; k++) {
        long long n = 1LL << k;
        printf("n=%2lld: 2T(n/2)+n = %3lld   n*log2(n)+n = %3lld\n", n, mergeT(n), n * k + n);
    }
    printf("T(n)=T(n-1)+n, n=10: %lld = n(n+1)/2 = %d\n", linearT(10), 10 * 11 / 2);
    printf("T(n)=2T(n-1)+1, n=10: %lld = 2^n - 1 = %d\n", hanoiT(10), (1 << 10) - 1);
    int cases[6][3] = {{2, 2, 1}, {1, 2, 0}, {8, 2, 2}, {2, 2, 2}, {7, 2, 2}, {3, 4, 1}};
    for (auto& c : cases)
        printf("a=%d b=%d d=%d: log_b a = %.2f -> %s\n", c[0], c[1], c[2], log((double)c[0]) / log((double)c[1]), master(c[0], c[1], c[2]).c_str());
}

Java · Recurrence.java

// Lecture 4: evaluating recurrences and the Master Theorem.
public class Recurrence {
    static long mergeT(long n) { return n == 1 ? 1 : 2 * mergeT(n / 2) + n; }   // T(n) = 2T(n/2) + n
    static long linearT(long n) { return n == 1 ? 1 : linearT(n - 1) + n; }     // T(n) = T(n-1) + n
    static long hanoiT(long n) { return n == 1 ? 1 : 2 * hanoiT(n - 1) + 1; }   // T(n) = 2T(n-1) + 1

    static String master(int a, int b, int d) {      // T(n) = a T(n/b) + Theta(n^d)
        double e = Math.log(a) / Math.log(b);
        if (Math.abs(e - d) < 1e-9) return d == 0 ? "Theta(log n)" : d == 1 ? "Theta(n log n)" : "Theta(n^" + d + " log n)";
        if (d > e) return d != 1 ? "Theta(n^" + d + ")" : "Theta(n)";
        if (Math.abs(e - Math.round(e)) > 1e-9) return String.format("Theta(n^%.2f)", e);
        return "Theta(n^" + Math.round(e) + ")";
    }

    public static void main(String[] args) {
        for (int k = 0; k < 6; k++) {
            long n = 1L << k;
            System.out.printf("n=%2d: 2T(n/2)+n = %3d   n*log2(n)+n = %3d%n", n, mergeT(n), n * k + n);
        }
        System.out.println("T(n)=T(n-1)+n, n=10: " + linearT(10) + " = n(n+1)/2 = " + 10 * 11 / 2);
        System.out.println("T(n)=2T(n-1)+1, n=10: " + hanoiT(10) + " = 2^n - 1 = " + ((1 << 10) - 1));
        int[][] cases = {{2, 2, 1}, {1, 2, 0}, {8, 2, 2}, {2, 2, 2}, {7, 2, 2}, {3, 4, 1}};
        for (int[] c : cases)
            System.out.printf("a=%d b=%d d=%d: log_b a = %.2f -> %s%n", c[0], c[1], c[2], Math.log(c[0]) / Math.log(c[1]), master(c[0], c[1], c[2]));
    }
}

Chapter 10 / 13

Common confusions

ConfusionCorrection
“T(n) = 2T(n/2) + n is Θ(n) because each level is n.”There are log n levels; total n log n.
“The Master Theorem solves every recurrence.”Only a·T(n/b) + f(n) with constant a ≥ 1, b > 1 (and suitable f).
“Two recursive calls means 2ⁿ.”Only if the size decreases by a constant: 2T(n − 1). With 2T(n/2) it is polynomial.
“Back substitution is a proof.”It finds the pattern; a full proof confirms it by induction (substitution method).
“The base case does not matter.”It fixes constants and the exact value; for the Θ class, any constant base case gives the same result.
