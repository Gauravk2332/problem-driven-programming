Chapter 02 / 07

Understand the concept

Divide and conquer: split into smaller subproblems, recursively solve, combine. Merge sort divides by position, sorts halves, then merges by comparing their first unmerged entries. Base: length≤1. Merge invariant: output is sorted and contains exactly the consumed elements. Smallest remaining among two sorted lists is at a head; take it. Each element consumed once.

T(n)=2T(n/2)+Θ(n) → Θ(n log n)
Extra array Θ(n); recursive stack Θ(log n)

Greedy: make one locally chosen feasible step if a safe-choice proof exists. DP: define sufficient smaller state and combine all relevant choices, storing answers where states repeat. Unlike divide and conquer, overlapping subproblems motivate caching. Not every recursion is DP; not every iterative algorithm is greedy.

Chapter 03 / 07

Work through the reasoning

One example distinguishes the techniques: unlimited coins {1,3,4}, target 6. Largest-coin greedy chooses 4,1,1 (3 coins). DP computes the minimum for each amount from 0 to 6. Base d[0]=0; d[s]=1+min(d[s−c]) over positive coins c≤s with reachable remainder. Last coin identifies a smaller state; if its prefix were nonoptimal we could improve the whole answer. No coin can be used with a negative remainder.

DP chooses 3+3. With a denomination 1 all targets reachable; without it use infinity and skip unreachable transitions. O(kT) time, O(T) space for k coins and target T (pseudo-polynomial). This is a preview of Lectures 12 and 22, not a replacement.

def merge_sort(a):
    if len(a)<=1:return a[:]
    m=len(a)//2
    l,r=merge_sort(a[:m]),merge_sort(a[m:])
    i=j=0;out=[]
    while i<len(l) and j<len(r):
        if l[i]<=r[j]:out.append(l[i]);i+=1
        else:out.append(r[j]);j+=1
    return out+l[i:]+r[j:]
print(merge_sort([8,3,5,1,9,2,6,4]))
