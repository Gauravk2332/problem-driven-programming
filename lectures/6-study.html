Chapter 01 / 07

Start with a problem

A teacher needs all primes from 1 to 30. Checking each candidate by trying every divisor smaller than it repeats a great deal of work. Can the fact that 2 is prime help us eliminate many candidates at once?

A prime is an integer greater than 1 with exactly two positive divisors, 1 and itself. Composite integers greater than 1 admit a nontrivial factor. Zero, one and negative integers are not prime under this definition. Two is the only even prime.

Chapter 02 / 07

Understand the mathematics

For one integer n≥2, trial division needs only possible divisors d≤√n. If n=ab and a,b>1, at least one factor is ≤√n; otherwise ab>n. Test d from 2 while d≤n/d. This integer condition avoids forming a potentially overflowing d². Return false on any divisor, true if none. Time O(√n) in the unit-cost model, auxiliary O(1). Checking many integers separately is often less attractive than preprocessing.

Sieve: mark 0 and 1 nonprime
For p=2 while p²≤N:
  if prime[p]: mark p²,p²+p,…≤N as composite

Initialize all indices 2..N as candidates. Smaller multiples of p already have a smaller prime factor; marking from p² avoids redundant work and does not mark p itself. Every composite n≤N has a least prime factor ≤√N, so it is eventually marked. A prime cannot be marked as a product of two integers greater than one.

Unmarked positions 2..30 give the ten primes above. The algorithm performs approximately N/p marking operations per prime p, summed to √N; the reciprocal-prime sum grows as O(log log N), giving O(N log log N) marking time for sufficiently large N, and O(N) initialization and storage. This is a standard number-theoretic estimate, not derived from a harmonic sum over all integers. Simple trial division for every number up to N has O(N√N) upper bound. A segmented sieve is an optional extension for large ranges with limited memory.

def is_prime(n):
    if n<2:return False
    d=2
    while d<=n//d:
        if n%d==0:return False
        d+=1
    return True
def sieve(n):
    if n<0:raise ValueError("nonnegative bound")
    prime=[True]*(n+1)
    prime[0]=False
    if n>=1:prime[1]=False
    p=2
    while p<=n//p:
        if prime[p]:
            for x in range(p*p,n+1,p):prime[x]=False
        p+=1
    return [i for i in range(2,n+1) if prime[i]]

Assume the bound fits available memory. Sieve returns an empty list for N=0 or 1; 49 is composite because 7 divides it. Use a wide type for marking increments. The array uses O(N) auxiliary storage (vector<bool> may pack bits). Returning a list also needs output storage. Trial division time depends on numerical n, not its bit length: O(√n) may be exponential in the number of bits.

Chapter 07 / 07

Exam revision

Prime >1 with two positive divisors; 0 and 1 nonprime. Trial division checks 2..√n in O(√n) time and O(1) space. Sieve initializes candidates and marks multiples from p² up to N for prime p≤√N. Least-prime-factor argument proves every composite marked. O(N log log N) time and O(N) storage. Pay attention to empty bounds and overflow.
