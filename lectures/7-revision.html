Lecture 7

Definitions

gcd: largest common divisor; lcm: smallest common multiple. gcd·lcm = ab. gcd(a, 0) = a. lcm = a / gcd × b (divide first).

Euclid

while b ≠ 0: (a, b) ← (b, a mod b)
return a

Proof: r = a − qb, so (a, b) and (b, r) share all common divisors.

Worked examples

a = q·b + r
252 = 2·105 + 42
105 = 2·42 + 21
42 = 2·21 + 0gcd 21

gcd(240, 46): q = 5, 4, 1, 1, 2; r = 10, 6, 4, 2, 0 ⇒ 2.

Speed

Remainder halves every two steps ⇒ O(log min(a, b)). Worst case: consecutive Fibonacci (89, 55): 9 divisions; (100, 55): 4.

Extended Euclid

extGcd(a, 0) = (a, 1, 0)
(g, x₁, y₁) = extGcd(b, a mod b)
return (g, y₁, x₁ − (a div b)·y₁)

240·(−9) + 46·47 = 2. ax + by = c solvable ⇔ gcd | c.

Common mistakes · full marks

  • Answer = last non-zero remainder.
  • a·b/gcd may overflow.
  • gcd(0, 0) undefined.

Full marks: lemma + proof, algorithm, full trace, O(log) reason, verified Bézout.

Two-mark self-test

  1. Define GCD and LCM.
    GCD: largest positive integer dividing both. LCM: smallest positive integer divisible by both.
  2. State the relation between GCD and LCM.
    gcd(a, b) × lcm(a, b) = a × b for positive a, b.
  3. Find gcd(48, 18) by Euclid.
    48 = 2·18 + 12; 18 = 1·12 + 6; 12 = 2·6 + 0 ⇒ 6.
  4. What is the time complexity of Euclid’s algorithm?
    O(log min(a, b)) divisions, because the remainder at least halves every two steps.
  5. State Bézout’s identity.
    For integers a, b not both zero there exist integers x, y with ax + by = gcd(a, b).
