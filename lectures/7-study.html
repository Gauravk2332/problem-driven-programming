Chapter 02 / 07

Understand the mathematics

GCD (greatest common divisor) and HCF (highest common factor) are the same. For nonnegative integers a,b, not both zero, gcd is the largest positive common divisor; define gcd(0,0)=0 by convention. gcd(a,0)=a. For signed inputs use absolute values, taking care at the minimum signed integer.

a=q·b+r, 0≤r<b
gcd(a,b)=gcd(b,a mod b)
while b≠0: (a,b)=(b,a mod b)
return a

If d divides a and b, then d divides a−qb=r. Conversely, if d divides b and r, it divides qb+r=a. The sets of common divisors are identical. Since the positive remainder is strictly smaller than b, the process terminates. This is a correctness proof, not merely a shortcut.

Return 21. The least common multiple of positive a,b obeys lcm(a,b)=ab/gcd(a,b), because writing a=gx,b=gy yields coprime x,y, so least common multiple is gxy. Compute (a/gcd)×b to reduce overflow risk. Define lcm(a,0)=0 including (0,0). Here lcm=12×105=1260.

Complexity derivation: in any two remainder steps, the smaller positive operand becomes less than half its original value. If r=a mod b is below b/2, the first step suffices. Otherwise the next remainder b mod r=b−r≤b/2 (strictly below except the equality case, which gives 0). Thus O(log min(a,b)) divisions for positive operands with min≥2, plus at most one initial swap if needed. Consecutive Fibonacci numbers give Θ(log min(a,b)) worst-case divisions. Iterative O(1) auxiliary space; recursive version O(log min(a,b)) stack. For large arbitrary-precision integers, each division itself has a nonconstant bit cost.

Implement and analyse

def gcd(a,b):
    a,b=abs(a),abs(b)
    while b:a,b=b,a%b
    return a
def lcm(a,b):
    if a==0 or b==0:return 0
    return abs((a//gcd(a,b))*b)
print(gcd(252,105),lcm(252,105))
#include <iostream>
using namespace std;
long long gcdNonneg(long long a,long long b){
 while(b){long long r=a%b;a=b;b=r;}
 return a;
}
long long lcmNonneg(long long a,long long b){
 return !a||!b?0:(a/gcdNonneg(a,b))*b;
}
int main(){cout<<gcdNonneg(252,105)<<" "<<lcmNonneg(252,105)<<"\n";}
class Main{
 static long gcd(long a,long b){
  while(b!=0){long r=a%b;a=b;b=r;}
  return a;
 }
 static long lcm(long a,long b){
  return a==0||b==0?0:Math.multiplyExact(a/gcd(a,b),b);
 }
 public static void main(String[] args){
  System.out.println(gcd(252,105)+" "+lcm(252,105));
 }
}

Expected output: 21 1260. Run locally; the website displays and copies code.

Python accepts signed arbitrary-precision integers. C++/Java examples require nonnegative operands; the C++ lcm product must fit signed 64-bit, and Java throws on overflow. Inputs with zero are handled explicitly. GCD is associative, so gcd of an array can be accumulated from 0; lcm can be accumulated from 1. For an empty collection those are identity conventions, not physical measurements. Extended Euclid also finds coefficients x,y with ax+by=gcd(a,b), useful in Lecture 8.

Exam revision

GCD/HCF: largest common divisor. gcd(a,b)=gcd(b,a mod b) from equal divisor sets. gcd(a,0)=a for nonnegative a. Iterative O(1) extra, logarithmic number of divisions. lcm=(a/gcd)×b for nonzero positive operands, otherwise 0. Example 252,105 → 42,21,0; gcd 21, lcm 1260. Avoid signed overflow.
