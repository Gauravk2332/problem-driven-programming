Modular Arithmetic

Modular arithmetic; modular inverse; binary exponentiation. Explore, calculate and practise.

Chapter 01 / 07

Start with a problem

Clock arithmetic wraps around: 10+5 hours on a 12-hour clock is 3, not 15. Similarly, with modulus 7, integers 3,10,17 and −4 represent the same residue class. We want to compute huge expressions without constructing huge intermediate values.

a ≡ b (mod m) iff m divides (a−b)
normalized residue r satisfies 0≤r<m

Congruence (≡) is not ordinary equality; it says the difference is a multiple of m. For programming, normalize negative remainders with ((a % m)+m)%m when m>0 (wide arithmetic if needed).

Chapter 02 / 07

Understand the mathematics

Addition, subtraction and multiplication can be reduced at each step: (a+b) mod m=((a mod m)+(b mod m)) mod m, similarly for subtraction and multiplication. Division is different: we cannot simply divide reduced residues. To divide by b modulo m, use b's multiplicative inverse when it exists.

b·b⁻¹ ≡ 1 (mod m)
a/b mod m means a·b⁻¹ mod m (only if gcd(b,m)=1)

Example: inverse of 3 modulo 7 is 5 since 3×5=15≡1. Solve 3x≡4 mod 7 by multiplying both sides by 5: x≡20≡6 mod 7. Check 3×6≡4. Inverse exists exactly when gcd(b,m)=1: Bézout's identity bx+my=1 constructs x, and if an inverse existed with gcd>1 that divisor would also divide 1, impossible. Work with m≥2. Under prime modulus p, Fermat's little theorem gives inverse b^(p−2) mod p for b not divisible by p; not a general composite-modulus formula.

Extended Euclid obtains x,y from gcd(b,m): if ax₁+by₁=g at a smaller remainder state, substituting r=a−qb gives new coefficients. More explicitly, from bx₁+ry₁=g we get ay₁+b(x₁−qy₁)=g, so return (y₁,x₁−qy₁). Example 7=2·3+1 → 1=7−2·3; inverse −2 normalized to 5.

Chapter 03 / 07

Work through the calculation

Compute a^e mod m with repeated squaring. If e is even, a^e=(a²)^(e/2); if odd, a^e=a·(a²)^floor(e/2). There is one smaller exponent, not two independent recursive calls; the squared base reuses the same value.

result=1 mod m; a=a mod m
while e>0:
  if e is odd: result=result·a mod m
  a=a·a mod m; e=floor(e/2)

3¹³ mod 17=12. Invariant: result·a^e is congruent to the original power. For an odd exponent, moving one factor to result and squaring the base preserves it; for an even exponent just square. At e=0 result is the answer. For e>0, floor(log₂ e)+1 loop iterations; O(log(e+1)) modular multiplications, O(1) auxiliary space iteratively. e=0 returns 1 mod m, including the programming convention for 0⁰. Negative exponents require an invertible base and are outside this implementation.

def egcd(a,b):
    if b==0:return a,1,0
    g,x,y=egcd(b,a%b)
    return g,y,x-(a//b)*y
def inverse(a,m):
    if m<2:raise ValueError("m >= 2")
    g,x,_=egcd(a%m,m)
    return x%m if g==1 else -1
def modpow(a,e,m):
    if e<0 or m<2:raise ValueError()
    a%=m;r=1
    while e:
        if e&1:r=r*a%m
        a=a*a%m;e//=2
    return r
print(inverse(3,7),modpow(3,13,17),inverse(6,9))

−1 denotes no inverse, not a residue. Fixed-width examples restrict 2≤m≤10⁹ so products of normalized residues fit signed 64-bit and extended Euclid coefficients/intermediate products are safely representable. Python integers are arbitrary precision; operations on very large integers cost more than constant time. Extended Euclid uses logarithmically many divisions and stack O(log m). Binary exponentiation requires O(1) auxiliary space and O(1+log(e+1)) unit-cost work, not O(e). For very large modulus use overflow-safe modular multiplication or a big-integer type.

Chapter 07 / 07

Exam revision

Congruence means equal residues, not equal integers. Reduce addition/subtraction/multiplication; normalize negatives. Modular division requires multiplicative inverse iff gcd=1 (m≥2). Extended Euclid gives Bézout coefficients; prime-modulus Fermat formula is conditional. Binary exponentiation: multiply result on odd bit, square base, halve exponent. O(log(e+1)) multiplications for e>0, constant iteration memory. Watch overflow.
