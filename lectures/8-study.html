Chapter 01 / 13

Start with a problem

A contest asks for 210¹⁸ modulo 1,000,000,007. The number 210¹⁸ has about 3 × 10¹⁷ digits; no computer can store it, and multiplying by 2 a quintillion times would take centuries.

Think first

Two ideas are needed. How can you keep every intermediate number small? How can you avoid 10¹⁸ multiplications?

Remainders and squaring
Reduce modulo m after every operation, so numbers never exceed m². And use 2^(2k) = (2^k)²: squaring repeatedly reaches exponent 10¹⁸ in about 60 steps. The answer is 719,476,260.

Modular arithmetic is the arithmetic of remainders. It keeps numbers bounded, which is why problems ask for answers “mod 10⁹ + 7”, and it underlies hashing (Lectures 10–11) and public-key cryptography.

Chapter 02 / 13

Remainders and congruence

For an integer a and modulus m > 0, a mod m is the remainder r with 0 ≤ r < m and a = qm + r. We write a ≡ b (mod m) (“a is congruent to b”) when m divides a − b, i.e. a and b leave the same remainder.

Python’s % already returns a value in [0, m) for positive m; C++ and Java do not. Forgetting this is a classic source of wrong answers with negative numbers.

Chapter 03 / 13

Operations that stay small

(a + b) mod m = ((a mod m) + (b mod m)) mod m
(a − b) mod m = ((a mod m) − (b mod m) + m) mod m
(a · b) mod m = ((a mod m) · (b mod m)) mod m

So you may reduce at every step. With m = 10⁹ + 7, each reduced value is below about 10⁹, and a product of two is below about 10¹⁸, which fits in a signed 64-bit integer (max ≈ 9.2 × 10¹⁸). In C++ and Java multiply as long long/long before reducing: (123,456,789 × 987,654,321) mod (10⁹ + 7) = 259,106,859, but the product overflows a 32-bit int.

Division is different. (a / b) mod m ≠ (a mod m)/(b mod m) in general: 12/4 = 3, but modulo 5 that is 2/4, which is not an integer. Division must be done by multiplying by a modular inverse (Chapter 7).

modPow(b, e, m):
  r ← 1 mod m;  b ← b mod m
  while e > 0:
    if e is odd: r ← r·b mod m
    b ← b·b mod m;  e ← e div 2
  return r

The loop runs ⌊log₂ e⌋ + 1 times: Θ(log e) multiplications. The recursive form is T(e) = T(e/2) + O(1) from Lecture 4. Starting with r = 1 mod m handles m = 1 correctly.

Chapter 06 / 13

Fermat’s little theorem

If p is prime and p does not divide a, then a^(p−1) ≡ 1 (mod p). Two uses:

  • Shrink exponents: 3¹² ≡ 1 (mod 13), so 3²⁰⁰ = 3^(12·16 + 8) ≡ 3⁸ (mod 13). (3³ = 27 ≡ 1 gives an even quicker route: 3²⁰⁰ ≡ 3² = 9.)
  • Inverses: a · a^(p−2) = a^(p−1) ≡ 1, so a⁻¹ ≡ a^(p−2) (mod p), computed with modPow.

Fermat’s theorem needs a prime modulus; for composite m, use extended Euclid instead. (Euler’s theorem generalises it: a^φ(m) ≡ 1 when gcd(a, m) = 1.)

Chapter 07 / 13

Modular inverses and division

The inverse of a modulo m is x with a·x ≡ 1 (mod m). It exists exactly when gcd(a, m) = 1.

a, mInverseMethod
3, 114 (3·4 = 12 ≡ 1)extended Euclid, or Fermat 3⁹ mod 11 = 4
4, 8nonegcd(4, 8) = 4 ≠ 1
2, 10⁹ + 7500,000,004Fermat: 2^(p−2) mod p
  • Extended Euclid (Lecture 7): solve a·x + m·y = 1; then x mod m is the inverse. Works for any m with gcd(a, m) = 1. O(log m).
  • Fermat: a^(m−2) mod m for prime m. O(log m).

To divide modulo p, multiply by the inverse: (a / b) mod p = a · b⁻¹ mod p, valid when b is not a multiple of p.

Chapter 08 / 13

Application: binomial coefficients mod p

C(n, r) = n! / (r!(n − r)!) involves division. Modulo a prime p > n, compute the numerator and denominator modulo p, then multiply by the inverse of the denominator.

C(n, r) mod p = [n(n−1)…(n−r+1) mod p] · [r! mod p]^(p−2) mod p

C(10, 3) = 120, and C(1000, 500) mod (10⁹ + 7) = 159,835,829, although C(1000, 500) itself has about 300 digits. For many queries, precompute factorials and inverse factorials once in O(n) and answer each C(n, r) in O(1).

Chapter 09 / 13

Modular arithmetic in code

The program shows negative remainders, a safe 64-bit product, modPow on three examples including exponent 10¹⁸, both inverse methods, and C(n, r) mod p.

Python · modular.py

"""Lecture 8: modular arithmetic, fast exponentiation, inverses."""
MOD = 1_000_000_007


def mod_pow(base, exp, m):
    result, base = 1 % m, base % m
    while exp > 0:
        if exp & 1:
            result = result * base % m
        base = base * base % m
        exp >>= 1
    return result


def ext_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = ext_gcd(b, a % b)
    return g, y1, x1 - (a // b) * y1


def mod_inverse(a, m):
    g, x, _ = ext_gcd(a % m, m)
    return None if g != 1 else x % m


def ncr_mod(n, r, p=MOD):
    if r < 0 or r > n:
        return 0
    num = den = 1
    for i in range(r):
        num = num * ((n - i) % p) % p
        den = den * ((i + 1) % p) % p
    return num * mod_pow(den, p - 2, p) % p


print("(-7) mod 3 =", (-7) % 3)
print("(123456789 * 987654321) mod 1e9+7 =", 123456789 * 987654321 % MOD)
print("3^200 mod 13 =", mod_pow(3, 200, 13))
print("2^10 mod 1000 =", mod_pow(2, 10, 1000))
print("2^(10^18) mod 1e9+7 =", mod_pow(2, 10 ** 18, MOD))
print("inverse of 3 mod 11 =", mod_inverse(3, 11), "| by Fermat:", mod_pow(3, 9, 11))
print("inverse of 4 mod 8 =", mod_inverse(4, 8))
print("C(10,3) mod p =", ncr_mod(10, 3), "| C(1000,500) mod p =", ncr_mod(1000, 500))

C++ · modular.cpp

// Lecture 8: modular arithmetic, fast exponentiation, inverses.
#include <cstdio>
#include <tuple>
using namespace std;
const long long MOD = 1000000007LL;

long long modPow(long long base, long long exp, long long m) {
    long long result = 1 % m;
    base %= m;
    while (exp > 0) {
        if (exp & 1) result = result * base % m;   // products < m^2 < 2^63 for m < 3e9
        base = base * base % m;
        exp >>= 1;
    }
    return result;
}

tuple<long long, long long, long long> extGcd(long long a, long long b) {
    if (b == 0) return {a, 1, 0};
    auto [g, x1, y1] = extGcd(b, a % b);
    return {g, y1, x1 - (a / b) * y1};
}

long long modInverse(long long a, long long m) {   // -1 if no inverse
    auto [g, x, y] = extGcd(a % m, m);
    return g != 1 ? -1 : ((x % m) + m) % m;
}

long long ncrMod(long long n, long long r, long long p = MOD) {
    if (r < 0 || r > n) return 0;
    long long num = 1, den = 1;
    for (long long i = 0; i < r; i++) {
        num = num * ((n - i) % p) % p;
        den = den * ((i + 1) % p) % p;
    }
    return num * modPow(den, p - 2, p) % p;
}

int main() {
    printf("(-7) mod 3 = %d\n", ((-7 % 3) + 3) % 3);            // C++ % can be negative
    printf("(123456789 * 987654321) mod 1e9+7 = %lld\n", 123456789LL * 987654321LL % MOD);
    printf("3^200 mod 13 = %lld\n", modPow(3, 200, 13));
    printf("2^10 mod 1000 = %lld\n", modPow(2, 10, 1000));
    printf("2^(10^18) mod 1e9+7 = %lld\n", modPow(2, 1000000000000000000LL, MOD));
    printf("inverse of 3 mod 11 = %lld | by Fermat: %lld\n", modInverse(3, 11), modPow(3, 9, 11));
    long long inv = modInverse(4, 8);
    printf("inverse of 4 mod 8 = %s\n", inv < 0 ? "None" : "exists");
    printf("C(10,3) mod p = %lld | C(1000,500) mod p = %lld\n", ncrMod(10, 3), ncrMod(1000, 500));
}

Java · Modular.java

// Lecture 8: modular arithmetic, fast exponentiation, inverses.
public class Modular {
    static final long MOD = 1_000_000_007L;

    static long modPow(long base, long exp, long m) {
        long result = 1 % m;
        base %= m;
        while (exp > 0) {
            if ((exp & 1) == 1) result = result * base % m;   // products < m^2 < 2^63 for m < 3e9
            base = base * base % m;
            exp >>= 1;
        }
        return result;
    }

    static long[] extGcd(long a, long b) {
        if (b == 0) return new long[]{a, 1, 0};
        long[] r = extGcd(b, a % b);
        return new long[]{r[0], r[2], r[1] - (a / b) * r[2]};
    }

    static long modInverse(long a, long m) {   // -1 if no inverse
        long[] r = extGcd(a % m, m);
        return r[0] != 1 ? -1 : Math.floorMod(r[1], m);
    }

    static long ncrMod(long n, long r, long p) {
        if (r < 0 || r > n) return 0;
        long num = 1, den = 1;
        for (long i = 0; i < r; i++) {
            num = num * ((n - i) % p) % p;
            den = den * ((i + 1) % p) % p;
        }
        return num * modPow(den, p - 2, p) % p;
    }

    public static void main(String[] args) {
        System.out.println("(-7) mod 3 = " + Math.floorMod(-7, 3));         // Java % can be negative
        System.out.println("(123456789 * 987654321) mod 1e9+7 = " + 123456789L * 987654321L % MOD);
        System.out.println("3^200 mod 13 = " + modPow(3, 200, 13));
        System.out.println("2^10 mod 1000 = " + modPow(2, 10, 1000));
        System.out.println("2^(10^18) mod 1e9+7 = " + modPow(2, 1_000_000_000_000_000_000L, MOD));
        System.out.println("inverse of 3 mod 11 = " + modInverse(3, 11) + " | by Fermat: " + modPow(3, 9, 11));
        long inv = modInverse(4, 8);
        System.out.println("inverse of 4 mod 8 = " + (inv < 0 ? "None" : "exists"));
        System.out.println("C(10,3) mod p = " + ncrMod(10, 3, MOD) + " | C(1000,500) mod p = " + ncrMod(1000, 500, MOD));
    }
}

modPow and both inverse methods are O(log) multiplications; ncrMod is O(r + log p). Copy and run it locally; this website shows code but does not execute it.

  • All products are taken in 64-bit arithmetic; with m up to about 3 × 10⁹ the product of two reduced values still fits.
  • For moduli near 10¹⁸, products overflow 64 bits: use __int128 (C++), Math.multiplyHigh/BigInteger (Java), or Python’s unbounded integers.

Practise

  1. Basic. Compute 7²²² mod 10 (the last digit).
    Answer
    7⁴ ≡ 1 (mod 10); 222 = 4·55 + 2, so 7²²² ≡ 49 ≡ 9.
  2. Core. Find the inverse of 7 modulo 26 by extended Euclid.
    Answer
    26 = 3·7 + 5, 7 = 1·5 + 2, 5 = 2·2 + 1 ⇒ 1 = 3·26 − 11·7 ⇒ inverse = −11 ≡ 15. Check 7·15 = 105 = 4·26 + 1.
  3. Core. Trace modPow(5, 13, 11).
    Answer
    13 = 1101₂: bases 5, 3, 9, 4; result 5 → 5 → 1 → 4. So 5¹³ ≡ 4 (mod 11).
