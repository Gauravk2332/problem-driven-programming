Catalan numbers

C₀ = 1, Cₙ = Σ Cᵢ·C(n−1−i)   = C(2n, n)/(n + 1)

1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796.

Derivation

Balanced string = ( A ) B, A has i pairs, B has n − 1 − i; independent ⇒ product; sum over i. DP table Θ(n²).

Interpretations (size n)

StructureCount
bracket strings, n pairsCₙ
binary trees / BSTs, n nodesCₙ
triangulations of (n+2)-gonCₙ
parenthesisings of n+1 factorsCₙ
paths below diagonal, n×nCₙ

Pigeonhole

n + 1 objects in n boxes ⇒ a box with ≥ 2. Generalised: N in k ⇒ ≥ ⌈N/k⌉. 13 people → shared month; 100 students → a month with ≥ 9.

In algorithms

Prefix sums mod n ⇒ subarray divisible by n ([3,1,4,1,5]: 1 + 4). More keys than slots ⇒ hash collision. n + 1 values in 1…n ⇒ duplicate.

Common mistakes · full marks

  • Cₙ ≠ C(2n, n): divide by n + 1.
  • (n + 2)-gon, not n-gon.
  • Pigeonhole proves existence only.

Full marks: decomposition → recurrence → values → closed form check → applications.

Two-mark self-test

  1. Write the first six Catalan numbers.
    C₀ … C₅ = 1, 1, 2, 5, 14, 42.
  2. State the closed form of Cₙ.
    Cₙ = C(2n, n)/(n + 1).
  3. State the pigeonhole principle.
    If more than n objects are placed in n boxes, at least one box contains two or more objects.
  4. Give two applications of Catalan numbers.
    Balanced bracket strings; binary trees with n nodes; triangulations of an (n + 2)-gon; parenthesising products.
  5. Show that among 13 people two share a birth month.
    13 people (objects), 12 months (boxes); 13 > 12 ⇒ two in one month.
