Chapter 01 / 07

Start with a problem

How many balanced strings can be built using n pairs of parentheses? For n=0 there is one empty string; n=1 has (). n=2 has (()) and ()(). For n=3, list all possibilities without repeating a string.

Reveal five possibilities

((())), (()()), (())(), ()(()), ()()().

Catalan numbers count many equivalent recursive structures: balanced parentheses, full ordered binary trees with n internal nodes, and triangulations of a convex (n+2)-gon for n≥1. The shared structure is an outer choice dividing the object into two independent smaller objects.

Chapter 02 / 07

Understand the mathematics

Every nonempty balanced parentheses string decomposes uniquely into ( A ) B, where the closing bracket matching the first open bracket determines A and B. If A has i pairs, B has n−1−i pairs. For fixed i, choices multiply; different i are disjoint, so add their counts.

C₀=1
Cₙ=Σᵢ₌₀ⁿ⁻¹ Cᵢ·Cₙ₋₁₋ᵢ
Cₙ = binom(2n,n)/(n+1) = (2n)!/(n!(n+1)!)

Closed form intuition: among binom(2n,n) strings with n opens and n closes, bad strings first cross below zero balance. Reflect the prefix through that crossing (swap opens and closes); this bijects bad strings with strings having n+1 opens and n−1 closes. Subtract binom(2n,n−1) to obtain binom(2n,n)/(n+1) for n≥1; n=0 is defined separately. Distinguish counting from generating all objects: outputting all balanced strings costs at least their total length.

Pigeonhole Principle

If N objects are placed into k≥1 boxes, at least one box contains at least ceil(N/k) objects. Otherwise every box would contain at most ceil(N/k)−1, totaling less than N. In particular N>k forces a repeated box.

A guarantee is a worst-case lower bound, not an exact distribution or probability. For example, 13 people may all share a birthday month, but at least two must. To guarantee three in one of 12 boxes, need 25 objects: 24 can be spread two per box. Hashing Lecture 10 uses this principle to explain unavoidable collisions.

def catalan(n):
    if n<0:raise ValueError()
    c=[0]*(n+1);c[0]=1
    for k in range(1,n+1):
        c[k]=sum(c[i]*c[k-1-i] for i in range(k))
    return c
def guarantee(N,k):
    if N<0 or k<=0:raise ValueError()
    return N//k+int(N%k!=0)

DP uses Θ(n²) arithmetic operations and Θ(n) cells, assuming constant-time arithmetic. Python integers are arbitrary precision, so bit costs grow. C++/Java cap n at 35 to remain safely within 64-bit bounds (C₃₅ fits; larger values require care). Exact counts grow rapidly. For modular counts, use wide products or appropriate modular multiplication. The closed form can be evaluated without raw factorials using arbitrary precision or a suitable modular method; do not divide mod m without checking invertibility. Pigeonhole count assumes N≥0, k≥1; integer quotient plus remainder avoids N+k−1 overflow.
