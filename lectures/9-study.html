Chapter 01 / 13

Start with a problem

How many ways can you write 3 pairs of brackets so that they are balanced (every “)” closes an earlier “(”)?

Think first

List them systematically. Then guess how many there are for 4 pairs.

Five strings
((())), (()()), (())(), ()(()), ()()(). For 4 pairs there are 14, for 10 pairs 16,796. Listing stops being practical quickly; we need a formula.

The sequence 1, 1, 2, 5, 14, 42, … is the Catalan numbers, Cₙ. It counts dozens of different structures in computer science. This lecture derives it, then turns to the pigeonhole principle, a counting argument that proves collisions and repeats must exist.

Chapter 02 / 13

Deriving the recurrence

Every non-empty balanced string starts with “(”. Look at the “)” that matches it. Between them is a balanced string with some number i of pairs; after it is a balanced string with the remaining n − 1 − i pairs:

( A ) B    with A of i pairs and B of n − 1 − i pairs

Choices for A and B are independent, so there are Cᵢ · C(n−1−i) strings for each i. Adding over i = 0 … n − 1:

C₀ = 1,   Cₙ = Σ (i = 0 … n−1) Cᵢ · C(n−1−i)

For n = 3: C₀C₂ + C₁C₁ + C₂C₀ = 2 + 1 + 2 = 5. This is a dynamic-programming recurrence: each Cₙ uses all smaller values, which a table computes in Θ(n²) time.

In the decomposition ( A ) B, why is the count a product Cᵢ · C(n−1−i)?

Chapter 05 / 13

The closed form

Cₙ = (1 / (n + 1)) · C(2n, n) = (2n)! / ((n + 1)! · n!)

Check: C₅ = C(10, 5)/6 = 252/6 = 42. The program confirms the formula against the recurrence for n = 0 … 10.

Why (sketch): the reflection argument

A bracket string of n “(” and n “)” is a path of up-steps and down-steps; there are C(2n, n) of them. A bad path dips below zero; reflecting its part after the first dip turns it into a path with n + 1 down-steps, and this is a one-to-one correspondence. Bad paths number C(2n, n + 1), so good ones number C(2n, n) − C(2n, n + 1) = C(2n, n)/(n + 1).

Growth: Cₙ ≈ 4ⁿ / (n^1.5 √π), exponential. Generating all Cₙ structures can never be polynomial, but counting them is easy.

Chapter 07 / 13

The pigeonhole principle

Pigeonhole principle. If n + 1 objects are placed in n boxes, some box holds at least two. Generalised: if N objects go into k boxes, some box holds at least ⌈N/k⌉.

SituationBoxesConclusion
13 people12 birth monthstwo share a month
100 students12 monthssome month has ≥ ⌈100/12⌉ = 9
n + 1 integersn remainders mod ntwo have the same remainder
[17, 4, 25, 11, 9]4 remainders mod 417 and 25 (both ≡ 1)
More keys than table slotsm slotsa hash collision is unavoidable (Lecture 10)

The principle proves that something exists without saying where. In algorithms that is often enough: it guarantees a loop will find a repeat, or that a solution exists.

Chapter 08 / 13

Pigeonhole in algorithms

Subarray with sum divisible by n. Any array of n integers has a non-empty contiguous subarray whose sum is divisible by n. Proof: the n + 1 prefix sums P₀ = 0, P₁, …, Pₙ have only n possible remainders mod n, so two are equal, Pᵢ ≡ Pⱼ; the subarray between them has sum Pⱼ − Pᵢ ≡ 0.

For [3, 1, 4, 1, 5] (n = 5) the prefix remainders are 0, 3, 4, 3, …: P₁ ≡ P₃ ≡ 3, so elements at indices 1 and 2 (1 + 4 = 5) work. The program finds this in one pass with a hash map from remainder to first position.

Duplicate in 1…n. An array of n + 1 values from 1 to n must contain a repeat. Floyd’s cycle-finding solves LeetCode 287 in O(n) time and O(1) space using that fact.

Why must two of the prefix remainders P₀ … Pₙ coincide?

Python · catalan.py

"""Lecture 9: Catalan numbers and the pigeonhole principle."""


def catalan_dp(n):
    c = [0] * (n + 1)
    c[0] = 1
    for k in range(1, n + 1):
        c[k] = sum(c[i] * c[k - 1 - i] for i in range(k))
    return c


def binom(n, r):
    res = 1
    for i in range(r):
        res = res * (n - i) // (i + 1)
    return res


def parens(n, cur="", opened=0, closed=0, out=None):
    out = [] if out is None else out
    if len(cur) == 2 * n:
        out.append(cur)
        return out
    if opened < n:
        parens(n, cur + "(", opened + 1, closed, out)
    if closed < opened:
        parens(n, cur + ")", opened, closed + 1, out)
    return out


def same_remainder(nums, m):
    seen = {}
    for x in nums:
        r = x % m
        if r in seen:
            return seen[r], x
        seen[r] = x
    return None


def divisible_subarray(a):
    n, prefix, first = len(a), 0, {0: 0}
    for i, x in enumerate(a, 1):
        prefix = (prefix + x) % n
        if prefix in first:
            return first[prefix], i - 1
        first[prefix] = i
    return None


c = catalan_dp(10)
print("C0..C10 =", c)
print("binomial formula agrees:", all(c[n] == binom(2 * n, n) // (n + 1) for n in range(11)))
p = parens(3)
print("balanced strings, n=3:", len(p), p)
print("two of [17, 4, 25, 11, 9] with equal remainder mod 4:", same_remainder([17, 4, 25, 11, 9], 4))
lo, hi = divisible_subarray([3, 1, 4, 1, 5])
print(f"[3, 1, 4, 1, 5]: indices {lo}..{hi} sum to {sum([3, 1, 4, 1, 5][lo:hi + 1])}, divisible by 5")

C++ · catalan.cpp

// Lecture 9: Catalan numbers and the pigeonhole principle.
#include <cstdio>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;

vector<long long> catalanDp(int n) {
    vector<long long> c(n + 1, 0);
    c[0] = 1;
    for (int k = 1; k <= n; k++)
        for (int i = 0; i < k; i++) c[k] += c[i] * c[k - 1 - i];
    return c;
}

long long binom(int n, int r) {
    long long res = 1;
    for (int i = 0; i < r; i++) res = res * (n - i) / (i + 1);   // exact at every step
    return res;
}

void parens(int n, string cur, int opened, int closed, vector<string>& out) {
    if ((int)cur.size() == 2 * n) { out.push_back(cur); return; }
    if (opened < n) parens(n, cur + "(", opened + 1, closed, out);
    if (closed < opened) parens(n, cur + ")", opened, closed + 1, out);
}

bool sameRemainder(const vector<int>& nums, int m, int& x, int& y) {
    unordered_map<int, int> seen;
    for (int v : nums) {
        int r = v % m;
        if (seen.count(r)) { x = seen[r]; y = v; return true; }
        seen[r] = v;
    }
    return false;
}

bool divisibleSubarray(const vector<int>& a, int& lo, int& hi) {
    int n = a.size(), prefix = 0;
    unordered_map<int, int> first = {{0, 0}};
    for (int i = 1; i <= n; i++) {
        prefix = (prefix + a[i - 1]) % n;
        if (first.count(prefix)) { lo = first[prefix]; hi = i - 1; return true; }
        first[prefix] = i;
    }
    return false;
}

int main() {
    vector<long long> c = catalanDp(10);
    printf("C0..C10 = [");
    for (int i = 0; i <= 10; i++) printf("%s%lld", i ? ", " : "", c[i]);
    printf("]\n");
    bool ok = true;
    for (int n = 0; n <= 10; n++) ok = ok && c[n] == binom(2 * n, n) / (n + 1);
    printf("binomial formula agrees: %s\n", ok ? "True" : "False");
    vector<string> p;
    parens(3, "", 0, 0, p);
    printf("balanced strings, n=3: %zu [", p.size());
    for (size_t i = 0; i < p.size(); i++) printf("%s'%s'", i ? ", " : "", p[i].c_str());
    printf("]\n");
    int x, y;
    sameRemainder({17, 4, 25, 11, 9}, 4, x, y);
    printf("two of [17, 4, 25, 11, 9] with equal remainder mod 4: (%d, %d)\n", x, y);
    vector<int> a = {3, 1, 4, 1, 5};
    int lo, hi;
    divisibleSubarray(a, lo, hi);
    int s = 0;
    for (int i = lo; i <= hi; i++) s += a[i];
    printf("[3, 1, 4, 1, 5]: indices %d..%d sum to %d, divisible by 5\n", lo, hi, s);
}

Java · Catalan.java

// Lecture 9: Catalan numbers and the pigeonhole principle.
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Catalan {
    static long[] catalanDp(int n) {
        long[] c = new long[n + 1];
        c[0] = 1;
        for (int k = 1; k <= n; k++)
            for (int i = 0; i < k; i++) c[k] += c[i] * c[k - 1 - i];
        return c;
    }

    static long binom(int n, int r) {
        long res = 1;
        for (int i = 0; i < r; i++) res = res * (n - i) / (i + 1);   // exact at every step
        return res;
    }

    static void parens(int n, String cur, int opened, int closed, List<String> out) {
        if (cur.length() == 2 * n) { out.add(cur); return; }
        if (opened < n) parens(n, cur + "(", opened + 1, closed, out);
        if (closed < opened) parens(n, cur + ")", opened, closed + 1, out);
    }

    static int[] sameRemainder(int[] nums, int m) {
        Map<Integer, Integer> seen = new HashMap<>();
        for (int v : nums) {
            int r = v % m;
            if (seen.containsKey(r)) return new int[]{seen.get(r), v};
            seen.put(r, v);
        }
        return null;
    }

    static int[] divisibleSubarray(int[] a) {
        int n = a.length, prefix = 0;
        Map<Integer, Integer> first = new HashMap<>();
        first.put(0, 0);
        for (int i = 1; i <= n; i++) {
            prefix = (prefix + a[i - 1]) % n;
            if (first.containsKey(prefix)) return new int[]{first.get(prefix), i - 1};
            first.put(prefix, i);
        }
        return null;
    }

    public static void main(String[] args) {
        long[] c = catalanDp(10);
        System.out.println("C0..C10 = " + java.util.Arrays.toString(c));
        boolean ok = true;
        for (int n = 0; n <= 10; n++) ok = ok && c[n] == binom(2 * n, n) / (n + 1);
        System.out.println("binomial formula agrees: " + (ok ? "True" : "False"));
        List<String> p = new ArrayList<>();
        parens(3, "", 0, 0, p);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < p.size(); i++) sb.append(i > 0 ? ", " : "").append("'").append(p.get(i)).append("'");
        System.out.println("balanced strings, n=3: " + p.size() + " [" + sb + "]");
        int[] r = sameRemainder(new int[]{17, 4, 25, 11, 9}, 4);
        System.out.println("two of [17, 4, 25, 11, 9] with equal remainder mod 4: (" + r[0] + ", " + r[1] + ")");
        int[] a = {3, 1, 4, 1, 5};
        int[] lh = divisibleSubarray(a);
        int s = 0;
        for (int i = lh[0]; i <= lh[1]; i++) s += a[i];
        System.out.println("[3, 1, 4, 1, 5]: indices " + lh[0] + ".." + lh[1] + " sum to " + s + ", divisible by 5");
    }
}

Catalan DP Θ(n²); generating all strings Θ(n · Cₙ); both pigeonhole searches Θ(n) with a hash map. Copy and run it locally; this website shows code but does not execute it.

  • C₃₅ ≈ 3.1 × 10¹⁸ is about the largest that fits in signed 64 bits; beyond that use big integers or compute modulo a prime (Lecture 8).
  • The binomial loop res = res·(n − i)/(i + 1) stays exact at each step because each intermediate value is itself a binomial coefficient.

Chapter 10 / 13

Common confusions

ConfusionCorrection
“Cₙ = C(2n, n).”Divide by n + 1: C(2n, n) counts all bracket strings, balanced or not.
“A triangulation of an n-gon is counted by Cₙ.”An (n + 2)-gon has Cₙ triangulations (a hexagon has C₄ = 14).
“Pigeonhole tells you which box.”It only guarantees existence.
“With n items in n boxes there must be a collision.”Only n + 1 (or more) items force one.
“The Catalan recurrence is divide and conquer.”Its subproblems overlap heavily; compute it bottom-up (DP).
